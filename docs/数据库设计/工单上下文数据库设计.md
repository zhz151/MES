# 工单上下文数据库设计（V4.7）

**版本**：V4.7
**最后更新**：2026-07-26

---

## 一、概述

本文档定义工单上下文的数据库设计，包括工单表（WorkOrder）和统一通知表（Notification）。

### 4.1 表名
`Notification`

### 4.2 字段定义

| 序号 | 字段 | 类型 | 必填 | 默认值 | 说明 | 生成方式 |
|------|------|------|------|--------|------|----------|
| **主键与通知标识** |
| 1 | Id | int | ✅ | 自增 | 主键 | 🔄 |
| 2 | NotificationType | nvarchar(30) | ✅ | - | 通知类型（7种）：NewMaterial/DeleteBlocked/OutboundAlert/WorkOrderDeleted/OrderDeleted/OrderChanged/WorkOrderChanged | ⚙️ |
| 3 | TargetId | int | ❌ | NULL | 关联目标ID（如 InventoryBatch.Id） | ⚙️ |
| **通知内容** |
| 4 | Title | nvarchar(200) | ✅ | - | 标题 | ⚙️ |

| 8 | CreatedTime | datetimeoffset | ✅ | GETUTCDATE() | 创建时间 | 📅 |

> **说明**：Notification 不使用 BaseEntity，无审计字段。原 OrderChangeNotification 表已废弃，功能迁移至统一通知体系。

### 4.3 索引

> **注：** 以下索引需在 AppDbContext 中补充配置，当前代码尚未添加。

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| PK_Notification | Id | 聚集 | 主键 |
| IX_Notification_NotificationType | NotificationType | 非聚集 | 按类型查询 |
| IX_Notification_IsRead | IsRead | 非聚集 | 查询未读数量 |
| IX_Notification_CreatedTime | CreatedTime | 非聚集 | 用于清理过期数据 |

### 4.4 通知类型说明

| NotificationType | 触发场景 | 触发位置 | UI展示 |
|------|------|------|------|
| NewMaterial | 新物料待审核 | MaterialService | 物料管理页面 |
| DeleteBlocked | 删除被阻止（有关联数据无法删除） | 各 Service | 操作页面 |
| OutboundAlert | 出库预警 | WarehouseService | 仓库管理页面 |
| WorkOrderDeleted | 工单被删除，已有入库批次引用该工单号 | WorkOrderService.DeleteAsync | InboundHistory页面 MudAlert提醒条 |
| OrderDeleted | 订单被删除，自动清理了关联工单 | OrderService.DeleteAsync | 统一通知体系 |
| OrderChanged | 订单项次发生变更（增/删/改） | OrderService.CreateItemChangedNotificationIfNeededAsync | WorkOrders页面 MudAlert提醒条 |
| WorkOrderChanged | 工单内容已变更（工单号不变，内容变） | WorkOrderService | 工单管理页面 |

## 十五、订单变更检测机制说明

### 15.1 依赖字段

工单变更检测依赖订单表（SalesOrder）中的 `LastItemChangeTime` 字段，该字段定义在**订单上下文**中：

| 字段 | 类型 | 说明 |
|------|------|------|
| LastItemChangeTime | datetimeoffset | 订单下项次的最后变更时间，在项次增、删、改时由系统自动更新 |

### 15.2 检测逻辑

```csharp
// 伪代码示例
// 定时任务每5分钟执行一次
var confirmedOrders = await _context.SalesOrders
    .Where(so => so.Status == SalesOrderStatus.Confirmed)
    .ToListAsync();

foreach (var order in confirmedOrders)
{
    var workOrders = await _context.WorkOrders
        .Where(wo => wo.SalesOrderNo == order.OrderNumber)
        .ToListAsync();

    if (!workOrders.Any()) continue;

    // 比较项次最后变更时间与工单创建时间
    if (order.LastItemChangeTime.HasValue && 
        order.LastItemChangeTime > workOrders.Max(wo => wo.CreatedTime))
    {
        // 订单项次发生过变更，工单状态变更为待修正
        foreach (var workOrder in workOrders)
        {
            if (workOrder.Status == WorkOrderStatus.Confirmed) // 已确定状态
                workOrder.Status = WorkOrderStatus.Pending;      // 变更为待修正
        }
    }
}
```

### 15.3 时序说明

| 场景 | LastItemChangeTime | 工单创建时间 | 检测结果 |
|------|-------------------|--------------|----------|
| 首次生成工单 | NULL | 2026-04-24 10:00 | 无变更，状态保持已确定 |
| 订单项次未变更 | 2026-04-24 09:00 | 2026-04-24 10:00 | 工单创建时间更新，无变更 |
| 订单项次已变更 | 2026-04-24 11:00 | 2026-04-24 10:00 | **检测到变更，状态变更为待修正** |
