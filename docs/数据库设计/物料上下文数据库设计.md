# 物料上下文数据库设计

**版本：V3.1**
**最后更新：2026-08-15**

---

## 一、概述

本文档定义物料上下文的数据库设计。物料上下文负责物资获取的全流程管理，包括采购执行和委外加工，通过字符串引用与工单上下文和仓库上下文松耦合衔接。

**当前范围（V3.2）：**
- 供应商档案（SupplierProfile）
- 采购订单（PurchaseOrder）
- 委外加工单（SubcontractOrder）
- 委外明细要求（SubcontractReturnItem）
- ~~物料档案（Material）~~ 已删除（2026-08-18）

**设计原则：**
- 一个采购订单只对应一项物料，无需采购项次（PurchaseOrderItem）
- 所有跨上下文的关联字段均为 **字符串（nvarchar）**，无物理FK约束
- 采购/委外单可选关联工单（SourceWorkOrderNo），通过工单中转查询销售订单/项次

## 五、PurchaseOrder（采购订单）

### 5.1 表名

`PurchaseOrder`

### 5.2 设计说明

采购订单采用 **一单一料** 设计，一个采购订单仅包含一项物料。无需独立的采购项次表，物料信息直接挂在采购订单上。

### 5.3 字段定义

| OrderNo | nvarchar(20) | ✅ | - | 采购单号（CG+yyMMdd+3位流水） | ⚙️ |
| SupplierId | int | ✅ | - | 供应商ID（→ SupplierProfile） | 👤 |
| SupplierName | nvarchar(200) | ❌ | - | 供应商名称（从 SupplierProfile 冗余快照） | 🔗 |
| OrderDate | date | ✅ | - | 下单日期 | 👤 |
| Status | nvarchar(20) | ✅ | 'Open' | Open/Partial/Completed（IsForceCompleted=false时自动计算） | 🧮 |
| IsForceCompleted | bit | ✅ | 0 | 强制完成（true时状态固定为Completed，false时自动计算） | 👤 |
| MaterialCategory | nvarchar(30) | ✅ | - | 物料分类 | 👤 |
| PlantGrade | nvarchar(50) | ✅ | - | 厂内钢种 | 👤 |
| Specification | nvarchar(100) | ✅ | - | 名义规格 | 👤 |
| UnitWeight | decimal(18,3) | ❌ | - | 单支重量(kg) | 👤 |
| InputMultiple | int | ❌ | - | 投料倍率（1制几） | 👤 |
| Quantity | int | ❌ | - | 采购支数 | 👤 |
| Weight | decimal(18,3) | ✅ | - | 采购重量(kg) | 👤 |
| RequiredDate | date | ✅ | - | 要求到货日期 | 👤 |
| UnitPrice | decimal(18,4) | ❌ | - | 单价 | 👤 |
| TotalAmount | decimal(18,2) | ❌ | - | 总金额 | 🧮 |
| **到货信息（Service自动维护）** |
| LastArrivalDate | date | ❌ | - | 最后到货日期 | 🧮 |

| SourceWorkOrderNo | nvarchar(50) | ❌ | - | 来源工单号（可选，追溯用料计划） | 👤 |
| Remark | nvarchar(500) | ❌ | - | 备注 | 👤 |
| CreatedTime | datetimeoffset | ✅ | GETUTCDATE() | 创建时间 | 📅 |
| CreatedBy | nvarchar(50) | ✅ | - | 创建人 | 📅 |
| UpdatedTime | datetimeoffset | ✅ | GETUTCDATE() | 更新时间 | 📅 |
| UpdatedBy | nvarchar(50) | ✅ | - | 更新人 | 📅 |

### 5.4 采购单号生成规则

格式：`CG + yyMMdd + 3位流水号`

示例：`CG260501001`

### 5.5 索引

| 索引名 | 字段 | 类型 |
|--------|------|------|
| PK_PurchaseOrder | Id | 聚集 |
| UK_PurchaseOrder_OrderNo | OrderNo | 唯一 |
| IX_PurchaseOrder_SupplierId | SupplierId | 非聚集 |
| IX_PurchaseOrder_Status | Status | 非聚集 |
| IX_PurchaseOrder_SourceWO | SourceWorkOrderNo | 非聚集 |
| IX_PurchaseOrder_RequiredDate | RequiredDate | 非聚集 |

### 5.6 业务规则

| 规则ID | 规则说明 |
|--------|----------|
| PO-001 | 采购单号由系统自动生成，格式 CG+yyMMdd+3位流水 |
| PO-002 | Status 枚举：Open=已下单，Partial=部分到货，Completed=已完成 |
| PO-003 | 采购单可独立存在，不强制关联工单（备料采购、常规补库） |
| PO-004 | SourceWorkOrderNo 为可选字段，用于追溯用料计划来源（字符串，无FK） |
| PO-005 | 一单一料：一个采购订单只包含一项物料，无需独立的项次表 |
| PO-006 | 到货进度由仓库入库记录触发：Service 按 SourceOrderNo 汇总 InventoryBatch 的入库数量/日期，入库/编辑/删除时自动增量同步，无需手动操作 |
| PO-007 | Status 自动计算规则：IsForceCompleted 为 false 时，ReceivedWeight=0 → Open，否则若 IsThresholdMet(ReceivedWeight, Weight, PurchaseCompleteRatio, PurchaseCompleteDeviation)（默认完成率≥96.5% 且绝对偏差≤200kg）→ Completed，其余 → Partial；IsForceCompleted 为 true 时直接设为 Completed |
| PO-008 | TotalAmount = Quantity × UnitPrice（若数量和单价均有值） |
| PO-009 | 物料字段（Category/Grade/Spec）为自由文本（存储 MaterialType 枚举名），无物理关联（物料档案表已删除） |
| PO-010 | 实物入库由仓库上下文完成，入库时记录 SourceOrderNo 追溯（仓库侧字段） |
| PO-011 | 如需追溯销售订单/项次，通过 SourceWorkOrderNo → WorkOrder.OrderNo 中转查询 |

| 索引名 | 字段 | 类型 |

| PK_SubcontractReturnItem | Id | 聚集 |

| IX_ReturnItem_OrderId | SubcontractOrderId | 非聚集 |

### 7.5 业务规则

| 规则ID | 规则说明 |
|--------|----------|
| RI-001 | ProcessStatus 枚举：Sent=已发出，PartialReturned=部分回收，Completed=已完成（已移除 Cancelled） |
| RI-002 | ReturnedQuantity/ReturnedWeight 由仓库入库事件驱动（SyncSourceOrdersAsync → SubcontractHelper.SyncReturnItemFromBatches）从 InventoryBatch 汇总：批次已按 SourceOrderNo 过滤，匹配键为 SourceOrderSequence == SubcontractReturnItem.Sequence |
| RI-003 | ProcessStatus 自动计算：IsForceCompleted=true → Completed；已回收=0 → Sent；已回收≥需求量 → Completed；否则 PartialReturned |
| RI-004 | IsForceCompleted 可由用户手动勾选，也可由主表 IsForceCompleted 级联设置（主表强制完成→子表全部强制完成） |
| RI-005 | MaterialCategory 在圆棒穿孔场景下始终为"荒管"，表示实际消耗的原料分类 |

## 八、编号规则统一说明

所有系统自动生成的单号遵循统一格式：

| 单号类型 | 前缀 | 格式 | 示例 |
|---------|------|------|------|
| 工单号 | {订单号}-{主号}[-{次号}] | {订单号}-{主号}[-{次号}]（主号由物料/长度决定前缀，后接序号） | PO2026001-D01-C01 |
| 批次号 | CK | CK + yyMMdd + 3位流水 | CK260501001 |
| 采购单号 | CG | CG + yyMMdd + 3位流水 | CG260501001 |
| 委外单号 | WW | WW + yyMMdd + 3位流水 | WW260501001 |

> **前缀含义：** GD=工单，CK=仓库，CG=采购，WW=委外
