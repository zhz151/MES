# 生产标准上下文数据库设计

**版本：V1.5**
**最后更新：2026-08-01**

---

## 一、实体关系图

```
StandardRegister (1) ──→ (N) StandardRegisterItem
      │
      │ (弱引用 StandardNo)
      ▼
  OrderItem.StandardNo (string)

StandardGradeMapping  (独立实体，无 FK)
GradeChemicalComposition (独立实体，无 FK)
GradePhysicalProperty (独立实体，无 FK)
ChemicalComposition (独立实体，无 FK)
ChemicalValidationRule (独立实体，无 FK)

GradeChemicalComposition  ←──→  StandardGradeMapping  (纯逻辑关联)
GradePhysicalProperty     ←──→  StandardGradeMapping  (纯逻辑关联)
  关联键: (StandardGrade, StandardGradeCategory)

ChemicalComposition  (独立实体，单键 PlantGrade)
ChemicalValidationRule  (独立实体，单键 PlantGrade)
  ChemicalValidationRule  ←──  FurnaceRegistration (质量上下文，业务引用 PlantGrade)

SubStandardQuickView   (独立实体，无 FK)
StandardInspectionRequirement  (独立实体，单键 StandardNo)
```

## 二、表结构

### 2.1 StandardRegister（标准号）

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| Id | int | PK, 自增 | 主键 |
| StandardNo | nvarchar(50) | NOT NULL, UNIQUE | 标准号（含版本信息） |
| StandardName | nvarchar(500) | NOT NULL | 标准名称 |
| RefSpecification | nvarchar(200) | NULL | 引用规范 |
| StandardLevel | nvarchar(20) | NULL | 标准级别 |
| ManufactureMethod | nvarchar(50) | NULL | 制造方式 |
| SteelType | nvarchar(50) | NULL | 钢类 |
| Remark | nvarchar(500) | NULL | 备注 |
| CreatedTime | datetimeoffset | NOT NULL | 创建时间 |
| CreatedBy | nvarchar(50) | NOT NULL | 创建人 |
| UpdatedTime | datetimeoffset | NOT NULL | 更新时间 |
| UpdatedBy | nvarchar(50) | NOT NULL | 更新人 |

**索引：**
- `PK_StandardRegister` ON Id (CLUSTERED)
- `UK_StandardRegister_StandardNo` ON StandardNo (UNIQUE)

### 2.2 StandardRegisterItem（标准号子项目）

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| Id | int | PK, 自增 | 主键 |
| StandardRegisterId | int | NOT NULL, FK → StandardRegister(Id) | 所属标准号 |
| SeqNo | int | NOT NULL | 序号 |
| InspectionCategory | nvarchar(50) | NULL | 检验类别 |
| InspectionItem | nvarchar(200) | NOT NULL | 检验项目 |
| IsMandatory | nvarchar(50) | NULL | 强制性（"关键"/"主要"/"一般"，string 非 bit） |
| SamplingRequirement | nvarchar(200) | NULL | 取样要求 |
| ApplicableRange | nvarchar(200) | NULL | 适用范围 |
| RefStandard | nvarchar(200) | NULL | 参考标准 |
| DetailRequirement | nvarchar(2000) | NULL | 详细要求 |
| CreatedTime | datetimeoffset | NOT NULL | 创建时间 |
| CreatedBy | nvarchar(50) | NOT NULL | 创建人 |
| UpdatedTime | datetimeoffset | NOT NULL | 更新时间 |
| UpdatedBy | nvarchar(50) | NOT NULL | 更新人 |

**索引：**
- `PK_StandardRegisterItem` ON Id (CLUSTERED)
- `IX_StandardRegisterItem_StandardRegisterId` ON StandardRegisterId
- `FK_StandardRegisterItem_StandardRegister` FOREIGN KEY (StandardRegisterId) → StandardRegister(Id)

> **注意：** StandardRegisterItem 没有 `(StandardRegisterId, SeqNo)` 唯一约束。前端 SaveAll 通过回写 item.Id 防止重复创建，但仍可能通过 DataExchange 导入或直接 DB 操作产生重复行。新增 `CleanupOrphanedItemsAsync()` 可从代码层面清理脏数据。

| MoMin | nvarchar(50) | NULL | Mo下限 |
| MoMax | nvarchar(50) | NULL | Mo上限 |
| CuMin | nvarchar(50) | NULL | Cu下限 |

| AlMin | nvarchar(50) | NULL | Al下限 |

**公式语法：** Min/Max 字段支持纯数值（如 `"0.04"`）和公式表达式（如 `"10×C%"`），实际阈值 = 系数 × C 值。当前支持 NbMin/TiMin 等与 C 含量成比例的元素。

> 此表原属质量上下文（`MES.Data.Entities.ChemicalValidationRule`），V7.2 逻辑归属迁移至生产标准上下文。表结构保持不变。
