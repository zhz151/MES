# 仓库上下文数据库设计（V7.2）

**版本**：V7.2
**最后更新**：2026-07-26

---

## 一、概述

本文档定义仓库上下文的数据库设计。仓库上下文属于核心上下文，负责库存管理、批次追踪、出入库记录等核心功能。

**当前范围**：
- 仓库档案（Warehouse）
- 库存批次（InventoryBatch）
- 出库记录（OutboundRecord）
- 批次删除日志（InventoryBatchDeleteLog）
- **库存计划（InventoryPlan）——实体文件在 Warehouse 命名空间，数据归属工单上下文管理**
- **库存计划工序组（InventoryPlanProcessGroup）——实体文件在 Warehouse 命名空间，子表 FK→InventoryPlan**

```sql
CREATE INDEX IX_InventoryBatch_RemainingWeight
ON InventoryBatch(RemainingWeight)
WHERE RemainingWeight > 0;
```

### 4.5 业务规则

| 规则ID | 规则说明 |
|--------|----------|
| IB-001 | 入库时 RemainingQuantity = InitialQuantity，RemainingWeight = InitialWeight |
| IB-002 | 出库时同步更新 RemainingQuantity 和 RemainingWeight |
| IB-003 | RemainingWeight = 0 时，批次不再出现在库存查询中 |

### 4.6 删除规则

| 条件 | 允许操作 | 处理方式 |
|------|----------|----------|
| RemainingWeight = 0 | 物理删除 | `_context.Remove()` |
| RemainingWeight > 0，入库 < 48小时，无关联出库，有权限 | 物理删除 | 真删除，记录日志 ✅ 已实现 |
| RemainingWeight > 0，其他情况 | 禁止删除 | 必须正常出库 |
