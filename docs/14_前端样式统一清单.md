### 2. 表格 Class 不统一
- `MudTable` 共 175 处（含跨行标签），原仅 81 处带 `Class="auto-table"`
- `compact-table` 在 app.css 有真实定义（紧凑表样式），多数列表页与 `auto-table` 并存属刻意
- 未加 `auto-table` 的表格走 MudBlazor 默认行高/字体/内边距 → 观感与已统一页不同
- **2026-08-20 已补齐 3 处**：Index:272（设备在修看板）、OrderCreate:130（订单项编辑表，改 `compact-table auto-table`）、WorkOrderInMainWorkOrderPlanCreate:95（可用批次选择表）；现 175 处全部含 `auto-table`，0 缺

### 3. 工具栏样式不统一
- 工单执行页用 `.woe-toolbar` class；Suppliers 等页用内联 `style="min-height:28px;..."` 模仿，无统一工具栏 class
- **2026-08-20 已统一**：app.css 定义 `.list-toolbar`（紧凑 28px/2px/flex，用户选定），50 文件 50 处 `woe-toolbar` → `list-toolbar` 并删除全部内联 `min-height:28px;...` 覆盖；原 23 处标准 36px 页随之统一为 28px，`woe-toolbar` 定义已移除，grep 零残留

### 4. 编辑控件属性不齐
- MudNumericField 202 处：`HideSpinButtons` 已 100% 覆盖（app.css 全局 CSS 兜底 + 属性全齐）
- `Format="G29"` 全量覆盖——**2026-08-20 补齐 decimal 12 处**（默认 decimal 7 + decimal? 5：CertificateCreate/CertificateDetail/WorkOrderInProcessReworkPlanCreate/WorkOrderInventoryPlanCreate×2/WorkOrderReworkPlanCreate×2/BatchReportDialog×3/RecoveryCreateDialog×2）；int/int? 64 处为整数无小数，G29 无意义不补；所有已有 Format 均已是 G29，无其他 Format 冲突
- `Dense="true"` 823 处与 `Size="Small"` 1258 处混用，同控件有的用 Dense、有的用 Size.Small（记录在案，未在收敛范围）
