**版本**：V5.6
**最后更新**：2026-09-04

## 一、概述

本文档定义批次上下文的接口设计，包括DTO、枚举、API端点。

**实现状态**：✅ 核心接口已实现

## 二、枚举定义

### 2.1 BatchStatus（批次状态）

**文件：** `MES.Core/Enums/BatchStatus.cs`

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | None | 未产 |
| 1 | InProgress | 在产 |
| 2 | Completed | 完成 |
| 3 | Suspended | 挂起（人工暂停） |
| 5 | InFinalInspection | 成检（已完成生产，处于成品检验阶段） |

### 2.3 PicklingStatus（酸洗入缸状态）

**文件：** `MES.Core/Enums/PicklingStatus.cs`
