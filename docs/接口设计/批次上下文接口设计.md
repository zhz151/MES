**版本**：V5.9
**最后更新**：2026-09-09

> V5.9（2026-09-09）：委外单位列表批十八 UX 细化——② 统计补金额：`OutsourceVendorProfileDto` 加 **`YearRecoveredAmount`**（本年回收[扣除退回]金额 = 各发出单 TotalAmount × Min(本年正常回收重,发出重)/发出重 分摊，退回不产生金额）、**`PendingAmount`**（委外未回收金额 = 待回收单 TotalAmount × 净欠重/发出重 分摊，净欠>0 才计）；前端列改名 `本年回收`→`本年回收[扣除退回]`、`在委外未回收`→`委外未回收`、本厂字段「本厂」外协留空、② 数据靠左（供应商页同）。无 EF 迁移、无列偏好键变更（仅标签/文案/CSS）。
>
> V5.8（2026-09-09）：委外单位档案列表建 ② 往来信息 统计列组（仿供应商）——`OutsourceVendorProfileDto` 加 9 统计字段（Total/Year 发出单数·吨·金额 + 本年回收/在委外未回收/本年退回 吨），`GetPagedAsync` 页内 `AttachTradeStatsAsync` 按 (名×工段) OrdinalIgnoreCase 分流回填（仅 !IsInternal 发出单；IsWorkshop 行/档外文本不计）；新增 `POST api/outsource-vendor/print-list-file`（Mode A，BatchView，前端组装 `OrderPrintListRequest` 转 PDF）。无 EF 迁移。

> V5.7（2026-09-09）：工段委外加 计价单位/单价/总价 三字段（`PricingUnit` 枚举复用、`MaterialPricingDefaults` 默认价 冷轧拔1.4/其它0.8、手填优先、厂内无价）；委外单位字段改**档案驱动**（Create/BatchCreate/Update 按 (名×工段) 命中启用档案 `OutsourceVendorProfile`，未建档/停用抛 BusinessException，仅单位实际变更时强制命中；`IsInternal` 由命中档案 `IsWorkshop` 派生、请求不再生效）；新增委外单位档案实体/服务/控制器（见 §3.17/§4.6 独立控制器）。

| GET | `api/pickling/{picklingInRecordId}/out-record` | 获取指定入缸的完工记录 | BatchViewer/BatchEditor/BatchFull/ReportViewer/ReportEditor/ReportFull/Admin |
| GET | `api/pickling/out-records/list` | 跨批次分页查询完工记录（关键词+CompleteDate范围+排序+筛选） | BatchViewer/BatchEditor/BatchFull/ReportViewer/ReportEditor/ReportFull/Admin |
| POST | `api/pickling/out-record` | 创建完工记录（自动更新入缸状态为Completed） | BatchEditor/BatchFull/Admin |
| PUT | `api/pickling/out-record/{id}` | 更新完工记录 | BatchEditor/BatchFull/Admin |
| DELETE | `api/pickling/out-record/{id}` | 删除完工记录（自动恢复入缸状态为Soaking） | Admin |
| GET | `api/pickling/out-records/filter-contexts` | 完工记录筛选上下文 | BatchViewer/BatchEditor/BatchFull/ReportViewer/ReportEditor/ReportFull/Admin |

#### 入缸记录查询参数（QueryParams 专用参数）

| 参数 | 类型 | 说明 |
|------|------|------|
| InDateFrom | DateTime? | 入缸日期范围（开始） |
| InDateTo | DateTime? | 入缸日期范围（结束） |
| CompleteDateFrom | DateTime? | 完工日期范围（开始，通过关联完工记录筛选） |
| CompleteDateTo | DateTime? | 完工日期范围（结束） |

支持排序列（24列）：batchno, processname, sectionname, manufacturingspec, indate, status, sequencenumber, tagno, plantgrade, remark, updatedtime, equipmentname, operator, shift, quantity, weight, isfinished, completedate, createdtime

#### 完工记录查询参数

| 参数 | 类型 | 说明 |
|------|------|------|
| CompleteDateFrom | DateTime? | 完工日期范围（开始） |
| CompleteDateTo | DateTime? | 完工日期范围（结束） |

支持排序列：completedate, createdtime
