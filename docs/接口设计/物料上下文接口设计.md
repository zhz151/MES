# 物料上下文接口设计

**版本：V3.9**
**最后更新：2026-09-04**

---

## 一、概述

本文档定义物料上下文的接口设计，包括DTO、API端点和业务规则。物料上下文涵盖供应商管理、采购订单执行（一单一料）和委外加工管理。

> **简化设计：** 已去除采购项次（PurchaseOrderItem），采购订单采用一单一料，物料信息直接挂在 PurchaseOrder 上。

### 2.8 采购执行状态DTO（ProcurementStatusDto）

**文件：** `MES.Core/DTOs/Materials/ProcurementStatusDto.cs`

| 字段 | 类型 | 说明 |
|------|------|------|
| WorkOrderNo | string | 工单号 |
| MaterialCategory | MaterialType? | 物料分类（MaterialType 枚举名，荒管/半成品/临界成品/订单成品） |
| PlantGrade | string? | 工厂牌号（取计划行级 PlantGrade，同工单同分类多牌号去重后顿号拼接） |
| MaterialName | string | 物料名称 |
| PlanWeight | decimal | 计划总量(kg) |
| PurchaseWeight | decimal | 已采购重量(kg，按 SourceWorkOrderNo 聚合 PurchaseOrder.Weight) |
| SubcontractWeight | decimal | 已委外重量(kg，按 SourceWorkOrderNo+MaterialCategory 聚合 SubcontractReturnItems.RequiredWeight) |
| TotalWeight | decimal | 合计已执行(kg) |
| StatusText | string | 状态文本（"未采购"/"部分采购"/"已采购"） |

> **说明：** 仅显示"未采购"（TotalWeight=0）和"部分采购"（TotalWeight未达阈值）的行。"已采购"（TotalWeight ≥ PlanWeight×96.5% 且 TotalWeight ≥ PlanWeight-200kg）不展示。
> 完成阈值判定：`IsThresholdMet(total, planWeight) => total >= planWeight * 0.965 && total >= planWeight - 200`
> 查询来源：遍历 PurchaseSemiPlan（按 RawMaterialType 拆分为荒管/半成品）和 PurchaseFinishedPlan（按 ProductType 拆分为临界成品/订单成品），按工单号+物料分类聚合对比。
> 圆棒穿孔场景：MaterialCategory 固定为"荒管"（圆棒穿孔实际消耗的是荒管原料）
> 工厂牌号（PlantGrade）：取计划行级（PurchaseSemiPlan/PurchaseFinishedPlan/RoundBarPiercingPlan.PlantGrade），同工单同分类多牌号去重后用顿号拼接显示；无计划行级牌号时为空。

**加载方式：** 全量加载+内存筛选。SQL 层仅做关键字搜索和状态筛选，DTO 投影时通过导航属性解析跨表字段（OrderNo/SupplierName/OrderDate/RequiredArrivalDate=ReturnDeadline），返回 List 后内存补充退货量与截止回收日（退货量经共享 helper `SubcontractHelper.AggregateReturnsBySequence` 按「委外单号×序号」归集：退货-原仓库批 ReturnSourceBatchNo 反查 InventoryBatch.BatchNo→SourceOrderNo==委外单号 且 SourceOrderSequence==序号，仅统计退货出库 ReturnOut，批次序号为空→归入序号0；截止回收日=同一批仓库批 InboundDate 最大值），再通过反射在内存中完成 ExcelFilter 多选/排序/分页。
