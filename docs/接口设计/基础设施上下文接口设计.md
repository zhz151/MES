# 基础设施上下文接口设计

**版本：V1.4**
**最后更新：2026-08-15**

---

## 一、概述

基础设施上下文提供认证授权（Auth）、用户管理（User）、扫码执行（Scan）三类 API 端点。所有接口统一返回 `ApiResponse<T>`。

**Base URL：** `/api`

---

## 二、认证 API（Auth）

**Controller：** `MES.Api.Controllers.Infrastructure.AuthController`
**路由：** `api/auth`

### 2.1 端点列表

| 方法 | 路由 | 权限 | 请求体 | 返回类型 | 说明 |
|------|------|------|--------|---------|------|
| POST | `api/auth/login` | 匿名 | `LoginRequest` | `ApiResponse<LoginResponse>` | 用户登录 |
| POST | `api/auth/refresh-token` | 匿名 | `RefreshTokenRequest` | `ApiResponse<LoginResponse>` | 刷新 Token |

### 2.2 DTO 定义

**LoginRequest**

| 字段 | 类型 | 说明 |
|------|------|------|
| Email | string | 用户邮箱 |
| Password | string | 用户密码 |

**LoginResponse**

| 字段 | 类型 | 说明 |
|------|------|------|
| Token | string | JWT Token |
| RefreshToken | string | 刷新 Token |
| RefreshTokenExpires | DateTime | 刷新 Token 过期时间 |
| Email | string | 用户邮箱 |
| UserName | string | 用户名 |
| FullName | string | 用户全名 |
| Roles | List\<string\> | 用户角色列表 |
| Expires | DateTime | Token 过期时间 |

**RefreshTokenRequest**

| 字段 | 类型 | 说明 |
|------|------|------|
| RefreshToken | string | 刷新 Token 值 |

---

## 三、用户管理 API（User）

**Controller：** `MES.Api.Controllers.Infrastructure.UserController`
**路由：** `api/users`
**权限：** 所有端点仅 `Admin` 角色可访问

### 3.1 端点列表

| 方法 | 路由 | 返回类型 | 说明 |
|------|------|---------|------|
| GET | `api/users/list` | `ApiResponse<PagedResult<UserDto>>` | 用户列表（分页） |
| POST | `api/users` | `ApiResponse<UserDto>` | 创建用户 |
| PUT | `api/users/{userId}` | `ApiResponse<UserDto>` | 更新用户 |
| PUT | `api/users/{userId}/reset-password` | `ApiResponse<object>` | 重置密码 |
| DELETE | `api/users/{userId}` | `ApiResponse<object>` | 删除用户 |

### 3.2 查询参数

| 参数 | 类型 | 说明 |
|------|------|------|
| PageIndex | int | 页码（默认 1） |
| PageSize | int | 每页条数（默认 20，最大 5000） |
| Keyword | string? | 模糊搜索关键字 |
| SortBy | string? | 排序列 |
| IsDescending | bool | 是否降序（默认 true） |

### 3.3 DTO 定义

**UserDto**

| 字段 | 类型 | 说明 |
|------|------|------|
| Id | string | 用户 ID |
| UserName | string | 用户名 |
| Email | string | 用户邮箱 |
| FullName | string? | 用户全名 |
| IsActive | bool | 是否激活 |
| Roles | List\<string\> | 用户角色列表 |
| LastLoginAt | DateTime? | 最后登录时间 |
| CreatedTime | DateTime | 创建时间 |

**CreateUserRequest**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| Email | string | ✅ | 用户邮箱 |
| Password | string | ✅ | 用户密码 |
| FullName | string? | ❌ | 用户全名 |
| UserName | string? | ❌ | 用户名 |
| Roles | List\<string\> | ✅ | 用户角色列表 |

**UpdateUserRequest**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| FullName | string? | ❌ | 用户全名 |
| IsActive | bool | ✅ | 是否激活（默认 true） |
| Roles | List\<string\> | ✅ | 用户角色列表 |

**ResetPasswordRequest**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| NewPassword | string | ✅ | 新密码 |

## 四、扫码执行 API（Scan）

**Controller：** `MES.Api.Controllers.Infrastructure.ScanController`
**路由：** `api/scan`
**权限：** 所有端点需 `[Authorize]`

### 4.1 端点列表

| 方法 | 路由 | 请求参数 | 返回类型 | 说明 |
|------|------|---------|---------|------|
| GET | `api/scan/resolve` | Query: batchNo, processGroupId | `ApiResponse<ScanResolveResultDto>` | 解析二维码，返回批次信息和可用工段列表 |
| GET | `api/scan/batch-groups` | Query: batchNo | `ApiResponse<ScanBatchResolveResultDto>` | 按批次号解析，返回该批次下所有工序组选项 |
| GET | `api/scan/resolve-equipment` | Query: code | `ApiResponse<ScanEquipmentResolveResultDto>` | 解析设备码，返回设备信息，用于扫码报修 |

### 4.2 DTO 定义

**ScanResolveResultDto**

| 字段 | 类型 | 说明 |
|------|------|------|
| BatchNo | string | 批次号 |
| PlantGrade | string | 厂内钢种 |
| ProcessGroupId | int | 工序组ID |
| ProcessName | string | 工序组名称 |
| ManufacturingSpec | string? | 制造规格 |
| AvailableSections | List\<SectionOption\> | 可用工段选项列表 |
| UnitWeight | decimal? | 单支重量（用于自动算重） |

**SectionOption**

| 字段 | 类型 | 说明 |
|------|------|------|
| SectionName | string | 工段名称 |
| SequenceNumber | int | 执行序号 |

**ScanBatchResolveResultDto**

| 字段 | 类型 | 说明 |
|------|------|------|
| BatchNo | string | 批次号 |
| Status | BatchStatus | 批次状态 |
| StatusDisplay | string | 批次状态中文显示 |
| PlantGrade | string | 厂内钢种 |
| Specification | string | 名义规格 |
| TagNo | string? | 挂牌号 |
| UnitWeight | decimal? | 单支重量（用于自动算重） |
| ProcessGroups | List\<ProcessGroupOption\> | 工序组选项列表 |

**ScanEquipmentResolveResultDto**

| 字段 | 类型 | 说明 |
|------|------|------|
| EquipmentId | int | 设备ID |
| EquipmentCode | string | 设备编码 |
| EquipmentName | string | 设备名称 |
| Location | string | 所在区域 |
| RelatedSection | string? | 关联工段 |
| ModelNumber | string? | 型号规格 |

**文件：** `MES.Core/DTOs/Infrastructure/ScanResolveResultDto.cs`、`ScanBatchResolveResultDto.cs`、`ScanEquipmentResolveResultDto.cs`
