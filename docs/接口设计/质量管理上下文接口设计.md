# 质量管理上下文接口设计（V8.3）

**版本**：V8.1
**最后更新**：2026-08-01

---

## 一、概述

本文档定义质量管理上下文的接口设计，包括DTO、枚举、API端点。

**当前实现**：
- ✅ 炉号登记（FurnaceRegistration）：完整 CRUD + 批量创建 + 牌号自动查询 + 化学成分验证
- ✅ 工厂牌号化学成分（ChemicalComposition）：完整 CRUD ✅（已迁移至生产标准上下文）
- ✅ 工厂牌号化分验证规则（ChemicalValidationRule）：完整 CRUD + 按工厂牌号查询 ✅（已迁移至生产标准上下文）
- ✅ 过程检验（ProcessInspection）：完整 CRUD + 跨批次分页查询
- ✅ 成品检验（FinalInspection）：完整 CRUD + 批量创建 + 批次信息自动调取 + 生产类型冗余
- ✅ 质量过程跟踪（QualityProcessTracking）：成检到料→成品检验→成品入库 整合读模型 + 分页查询
- ✅ 不合格品报告（NCR）：不合格品反馈→处置→分析→追责→纠正预防闭环，3 状态状态机（处理中/已关闭）
- ✅ 理化检测（V7.0 新增）：
  - ✅ 化学分析（ChemicalAnalysis）：光谱分析15元素 + CRUD + 批量创建
  - ✅ 硬度检验（HardnessTest）：硬度检测 CRUD + 批量创建
  - ✅ 晶粒度检验（GrainSizeTest）：晶粒度评级 CRUD + 批量创建
  - ✅ 扩口试验（FlaringTest）：扩口性能 CRUD + 批量创建
  - ✅ 压扁试验（FlatteningTest）：压扁性能 CRUD + 批量创建
  - ✅ 晶间腐蚀试验（IntergranularCorrosionTest）：晶间腐蚀 CRUD + 批量创建
  - ✅ 金相检验（MetallographicTest）：金相组织 CRUD + 批量创建
  - ✅ 点腐蚀试验（PittingCorrosionTest）：点腐蚀 CRUD + 批量创建
  - ✅ 室温拉伸试验（TensileTest）：室温拉伸 CRUD + 批量创建
- ✅ 质量证明书（Certificate）：完整 CRUD + 自动编号 + 头选项查询 + 检验数据自动填充 + 关联待发货模块
- ✅ 成检到料（MaterialReceiveCheck）：完整 CRUD + 强制完成 + 跨批次分页查询 + 打印
