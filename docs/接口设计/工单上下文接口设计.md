# 工单上下文接口设计（V6.9）

**版本**：V6.9
**最后更新**：2026-08-20

---

## 一、概述

本文档定义工单上下文的接口设计，包括枚举、DTO、API 端点、请求/响应示例、错误码等。**包含统一通知相关接口以及工单项次追溯接口**。

---

## 二、枚举定义

### 2.1 工单状态（WorkOrderStatus）

| 值 | 英文 | 说明 |
|----|------|------|
| 0 | NotGenerated | 未编制（订单从未生成过工单） |
| 1 | Confirmed | 已确定（工单与订单一致） |
| 2 | Pending | 待修正（订单已有工单，但订单变更，需重新生成） |

> **注意：** 工单状态为 3 态枚举（无 Cancelled）。已取消的订单其工单被物理删除，不存在独立状态。`IncludeCancelled=false` 时不在列表中显示。

### 2.2 长度状态（LengthStatus）

| 值 | 说明 |
|----|------|
| Fixed | 定尺 |
| Range | 范围尺 |
| NonFixed | 非定尺 |

### 2.3 物料名称（MaterialName）

| 值 | 说明 |
|----|------|
| WeldedPipe | 焊管 |
| SeamlessPipe | 无缝管 |

### 2.4 结算方式（SettlementMethod）

| 值 | 说明 |
|----|------|
| Weighing | 过磅 |
| WeighingNegative | 过磅-负 |
| Theoretical | 理算 |

### 2.5 交货状态（DeliveryState）

| 值 | 说明 |
|----|------|
| SolutionAnnealedAndPickled | 固溶酸洗 |
| SolutionAnnealedAndPickledUTube | 固溶酸洗-U型管 |
| SolutionAnnealedAndPickledExternalPolished | 固溶酸洗-外抛光 |
| SolutionAnnealedAndPickledInternalPolished | 固溶酸洗-内抛光 |
| SolutionAnnealedAndPickledBothPolished | 固溶酸洗-内外抛光 |
| SolutionAnnealedAndPickledCoiled | 固溶酸洗-盘管 |
| Bright | 光亮 |
| BrightUTube | 光亮-U型管 |
| BrightCoiled | 光亮-盘管 |
| Hard | 硬态 |
| SolidSolutionStraightening | 固溶矫直 |

### 2.6 通知类型（NotificationType）

| 值 | 说明 |
|----|------|
| NewMaterial | 新物料待审核 |
| DeleteBlocked | 删除被阻止 |
| OutboundAlert | 出库预警 |
| WorkOrderDeleted | 工单已删除（入库批次仍引用已删除的工单号，⚠️ 已废弃，仅兼容存量数据） |
| OrderDeleted | 订单已删除（自动清理了关联工单） |
| OrderChanged | 订单项次变更（关联工单可能需要更新） |
| WorkOrderChanged | 工单内容已变更（工单号不变，ManufacturingItem/PlantGrade/数量等变更） |

> **说明**：原 NotificationChangeType 枚举已废弃，统一迁移至 NotificationType 字符串类型。

### 2.7 用料计划状态（MaterialPlanStatus）

| 值 | 名称 | 含义 |
|----|------|------|
| 0 | NotPlanned | 未计划（没有任何明细的用料信息） |
| 1 | Partial | 部分（有部分计划，但满足率不足100%） |
| 2 | Satisfied | 满足（总量在合理范围内，含原"理论满足"区间） |
| 3 | Excess | 超量（总量超过了合理范围上限） |

### 2.8 库存计划状态（InventoryPlanStatus）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | Planned | 已计划（已创建计划，等待库房确认） |
| 1 | Confirmed | 已确认（库房已确认出库） |
| 2 | Cancelled | 已取消 |

### 2.9 改制类型（ReworkType）

> **注意**：ReworkType 在 InventoryPlan 实体中使用 `ReworkType?` 枚举类型 + `HasConversion<string>()` 映射存储为 nvarchar(20)。

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | EmptyDrawing | 空拉改制 |
| 1 | FewerPass | 少道次改制 |
| 2 | ManualSelect | 人工选择改制 |

### 2.10 成品类型（FinishedProductType）

| 值 | 名称 | 说明 |
|----|------|------|
| 1 | Critical | 临界成品（需要回厂复检） |
| 2 | Order | 订单成品（不需再检验） |

### 2.11 原料类型（RawMaterialType）

> 该枚举已合并至 MaterialType（15种物料类型，详见 `docs/01_设计总纲领.md` §6.7）。
> `RawMaterialType` DB 列仍保留原名，实体/DTO 字段类型改为 MaterialType。

| 值 | 说明 |
|----|------|
| Finished | 备料成品 |
| OrderFinished | 订单成品 |
| SemiFinished | 荒管/半成品 |
| RoundBar | 圆棒（穿孔用） |
| RoughTube | 荒管 |

### 2.12 工单生成模式（WorkOrderGenerateMode）

| 值 | 说明 |
|----|------|
| FirstTime | 首次生成：创建全新工单，生成全新主号/次号 |
| Regenerate | 覆盖生成：物理删除旧工单，按当前项次重新生成，保留原主号/次号 |
| Update | 更新修改：在旧工单基础上更新（新增/删除/修改项次），不删除旧工单，不改变已有项次的主号/次号 |

| ReservedQuantity | int | 已被部分使用计划预留的支数（仅统计未取消且未出库的部分使用计划） |

> 说明：可用量 = 物理剩余(RemainingQuantity/RemainingWeight) − 预留(ReservedQuantity/ReservedWeight)。「部分使用(Partial)」仅预留不锁定，批次仍可被下个工单搜索到（新计划累计预留 + 本次用量不得超过批次物理剩余）。
> **锁定/共享语义（2026-08-09 收紧）**：批次上存在任一有效计划（All 或 Partial，**含本工单自身的部分预留**，仅排除未取消且已生产领用出库的计划）→ **禁止再建「全部使用(All)」**（All=清空整批，任何预留存在都不可）。批次上存在 All → 整批锁定禁止再建 Partial；否则 Partial 可被多个工单共享（各自累计预留 ≤ 物理剩余）。出库阶段 OutboundWriteService 另有硬校验：出库量不得超过批次物理剩余。

## 六、错误码定义

| 错误码 | 说明 | 场景 |
|--------|------|------|
| 200 | 成功 | - |
| 400 | 业务错误 | 订单不存在、订单状态不是已确认、项次列表为空等 |
| 401 | 未认证 | 未提供或提供无效的JWT |
| 403 | 无权限 | 角色权限不足 |
| 404 | 资源不存在 | 工单ID不存在或通知ID不存在 |
| 409 | 并发冲突 | 乐观并发控制冲突 |
| 500 | 系统错误 | 服务器内部错误 |

### 业务错误示例

| 错误消息 | 说明 |
|----------|------|
| 订单 {orderNo} 不存在 | 订单号无效 |
| 订单 {orderNo} 状态不是已确认，无法生成工单 | 订单未确认 |
| 订单 {orderNo} 没有有效的项次 | 项次列表为空 |
| 主号前缀 {prefix} 已达到最大序号99，请手动调整 | 主号序号超限 |
| 次号不能为空 | 次号校验失败（2 位全模式非空） |
| 定尺模式下次号格式必须为两位数字（如 01），当前值：{productionSubNo} | 定尺次号格式错误（仅接受两位数字 01~99） |
| {长度状态}模式下次号必须为 F0，当前值：{productionSubNo} | 范围尺/非定尺次号格式错误（固定为 F0） |
| 工单已被其他用户修改，请刷新后重试 | 并发冲突 |
| 通知不存在 | 通知ID不存在 |
