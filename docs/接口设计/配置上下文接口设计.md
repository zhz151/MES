# 配置上下文接口设计

**版本：V2.1**
**最后更新：2026-08-26**

---

## 一、概述

本文档定义配置上下文（Configuration Context）的接口设计。配置上下文包含十个 CRUD 控制器：工段工量天数（StandardWorkDay）、交货状态附加天数（StandardWorkDayDeliveryState）、系统参数(全局参数)（ConfigParameter）、规格日产预估（DailyOutputEstimate）、重点工段日产（DailyProductionCapacity）、工位管理（Workstation）、员工管理（Employee）、枚举显示配置（EnumDisplayDefinition）、字典显示配置（DictValueDefinition）和工序组定义（ProcessDefinition），均提供完整的分页查询/获取/新增/更新/删除接口。

**功能定位：**
- 均为配置维护接口，权限按三档模型（ConfigurationViewer 查 / ConfigurationEditor 查增改 / ConfigurationFull 查增改删，Admin 全权），不涉及业务校验
- Service 层额外提供 `GetStandardDaysMapAsync` / `GetDeliveryStateExtraDaysMapAsync` / `GetConfigMapAsync` 方法供业务模块调用
- 前端页面为内联编辑模式（查改一体表）
- **枚举显示配置 / 字典显示配置 / 工序组定义（V1.9 新增）**：显示层参数化三表，管理枚举/字典/工序组的中文显示名、排序与启停（枚举/字典可改名排序、字典可隐藏加值、工序组可启停改默认工段）；接口额外提供 `display-map` / `options-map` / `enabled-values` / `enabled-processes` 等展示层端点供前端即时生效

### 核心能力

| 功能 | 说明 |
|------|------|
| 分页查询 | 关键字模糊搜索 + 通用筛选 + 排序 |
| 按 ID 获取 | 单条记录详情 |
| 新增/更新 | 统一 save 端点，Id > 0 时更新，Id = 0 时新增 |
| 删除 | 按 ID 删除 |

## 二、StandardWorkDay（工段工量天数）

### 2.1 基础路径

`api/standard-work-day`

### 2.2 接口端点

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/standard-work-day/list` | 分页查询 |
| GET | `/api/standard-work-day/enabled-sections` | 获取启用工段列表（展示层动态化用：SectionKey/SectionName/DisplayOrder/IsEnabled，IsEnabled=true 且按 SectionKey 去重、通用行优先、DisplayOrder 升序） |
| GET | `/api/standard-work-day/section-name-map` | 获取工段 Key → 显示中文 映射（配置表优先，兜底 SectionDefs） |
| GET | `/api/standard-work-day/{id}` | 按 ID 获取 |
| POST | `/api/standard-work-day/save` | 新增/更新 |
| POST | `/api/standard-work-day/delete/{id}` | 删除 |

### 2.3 请求参数

#### GET /api/standard-work-day/list

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageIndex | int | ✅ | 页码（从 1 开始） |
| pageSize | int | ✅ | 每页条数 |
| sortBy | string | ❌ | 排序字段，默认 SectionName |
| isDescending | bool | ❌ | 是否降序，默认 false |
| keyword | string | ❌ | 关键字模糊搜索（SectionName、PlantGradePrefix、Remark） |
| filters | string | ❌ | JSON 序列化的 FilterDescriptor 数组 |

#### GET /api/standard-work-day/{id}

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | ✅ | 记录 ID |

#### POST /api/standard-work-day/save

请求体（StandardWorkDayDto）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | ❌ | 0 时新增，> 0 时更新 |
| sectionName | string | ✅ | 工段名称（中文显示） |
| sectionKey | string? | ❌ | 稳定 Key（对应 SectionDefs 常量名，如 ColdRollDraw），程序识别工段用，不受改名影响 |
| displayOrder | int | ❌ | 显示顺序（升序，1 排最前） |
| isEnabled | bool | ❌ | 是否启用（false 表示隐藏，界面不显示该工段），默认 true |
| plantGradePrefix | string? | ❌ | 牌号前缀，null=通用 |
| standardDays | double | ✅ | 标准天数 |
| remark | string? | ❌ | 备注 |

#### POST /api/standard-work-day/delete/{id}

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | ✅ | 要删除的记录 ID |

### 2.4 响应格式

统一返回 `ApiResponse<T>` 格式：

```json
{
  "success": true,
  "data": { ... },
  "message": null
}
```

## 九、枚举显示配置 API（EnumDisplayDefinition）

**Controller：** `MES.Api.Controllers.Configuration.EnumDisplayDefinitionController`
**路由：** `api/enum-display-definition`
**权限：** list/get/save/delete 需 ConfigurationViewer/ConfigurationEditor/ConfigurationFull/Admin / ConfigurationEditor/ConfigurationFull/Admin；display-map / options-map 仅需登录（前端显示层即时生效）

管理所有 C# 强类型枚举的中文显示名与排序（不改值域）。`EnumKey` = 枚举类型名（typeof(T).Name），`Value` = 枚举值名（Enum.ToString()，稳定英文名）。显示层"配置表优先 → EnumHelper 静态字典兜底"；改名后 DataExchange 导出新中文，导入可反向解析。

### 9.1 端点列表

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/enum-display-definition/filter-contexts` | 列头筛选上下文（各筛选列可选值） |
| GET | `/api/enum-display-definition/list` | 分页查询 |
| GET | `/api/enum-display-definition/display-map` | 全量显示映射：EnumKey → Value → DisplayName（配置表优先，兜底 EnumHelper） |
| GET | `/api/enum-display-definition/options-map` | 全量显示选项：EnumKey → 有序 (Value/DisplayName/DisplayOrder)，供前端排序注入 |

## 十三、跨上下文调用接口

配置上下文提供三个字典查询方法供业务模块内部调用（非 API 端点，通过 DI 注入）：

### 13.1 GetStandardDaysMapAsync

```csharp
Task<Dictionary<string, double>> GetStandardDaysMapAsync(string? plantGrade)
```

- **用途**：获取工段名称 → 标准天数的映射字典
- **匹配规则**：按 SectionName 分组，优先取 PlantGradePrefix 精确匹配当前牌号，未找到则取通用（null）条目
- **调用方**：MaterialPlanService、MaterialPlanProcessGroupService、ProductionRecordService

### 13.2 GetDeliveryStateExtraDaysMapAsync

```csharp
Task<Dictionary<string, double>> GetDeliveryStateExtraDaysMapAsync()
```

- **用途**：获取交货状态枚举名 → 附加天数的映射字典（仅返回 PlantGradePrefix == null 的通用配置）
- **调用方**：MaterialPlanService、MaterialPlanProcessGroupService、ProductionRecordService

### 13.3 GetConfigMapAsync

```csharp
Task<Dictionary<string, decimal>> GetConfigMapAsync(string category)
```

- **用途**：获取指定分类下所有参数键 → 数值的映射字典
- **缓存策略**：每次 HTTP 请求独立加载（Service 为 Scoped 生命周期），修改配置后下一秒请求自动生效
- **调用方**：16 个业务 Service（详见 4.5 节）
