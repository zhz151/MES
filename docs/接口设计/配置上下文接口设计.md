# 配置上下文接口设计

**版本：V1.5**
**最后更新：2026-06-25**

---

## 一、概述

本文档定义配置上下文（Configuration Context）的接口设计。配置上下文包含六个 CRUD 控制器：工段标准工期（StandardWorkDay）、交货状态附加工期（StandardWorkDayDeliveryState）、默认配置-系统参数（ConfigParameter）、规格日产预估（DailyOutputEstimate）、重点工段日产（DailyProductionCapacity）和工位管理（Workstation），均提供完整的分页查询/获取/新增/更新/删除接口。

**功能定位：**
- 均为 AdminOnly 参数维护接口，不涉及业务校验
- Service 层额外提供 `GetStandardDaysMapAsync` / `GetDeliveryStateExtraDaysMapAsync` / `GetConfigMapAsync` 方法供业务模块调用
- 前端页面为内联编辑模式（查改一体表）

### 核心能力

| 功能 | 说明 |
|------|------|
| 分页查询 | 关键字模糊搜索 + 通用筛选 + 排序 |
| 按 ID 获取 | 单条记录详情 |
| 新增/更新 | 统一 save 端点，Id > 0 时更新，Id = 0 时新增 |
| 删除 | 按 ID 删除 |

### DTO 清单

| DTO | 文件 | 说明 |
|-----|------|------|
| StandardWorkDayDto | `MES.Core/DTOs/Configuration/StandardWorkDayDto.cs` | 标准工量天数 |
| StandardWorkDayDeliveryStateDto | `MES.Core/DTOs/Configuration/StandardWorkDayDeliveryStateDto.cs` | 交货状态附加天数 |
| ConfigParameterDto | `MES.Core/DTOs/Configuration/ConfigParameterDto.cs` | 业务参数配置 |
| DailyOutputEstimateDto | `MES.Core/DTOs/Configuration/DailyOutputEstimateDto.cs` | 日产估算 |
| DailyProductionCapacityDto | `MES.Core/DTOs/Configuration/DailyProductionCapacityDto.cs` | 重点工段日产 |
| WorkstationDto | `MES.Core/DTOs/Configuration/WorkstationDto.cs` | 工位管理 |
| EmployeeDto | `MES.Core/DTOs/Configuration/EmployeeDto.cs` | 员工基础信息 |
| SectionFlowCategorySettingDto | `MES.Core/DTOs/Configuration/SectionFlowCategorySettingDto.cs` | 工段分类设定 |

## 二、StandardWorkDay（标准工量天数）

### 2.1 基础路径

`api/standard-work-day`

### 2.2 接口端点

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/standard-work-day/list` | 分页查询 |
| GET | `/api/standard-work-day/{id}` | 按 ID 获取 |
| POST | `/api/standard-work-day/save` | 新增/更新 |
| POST | `/api/standard-work-day/delete/{id}` | 删除 |

### 2.3 请求参数

#### GET /api/standard-work-day/list

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageIndex | int | ✅ | 页码（从 1 开始） |
| pageSize | int | ✅ | 每页条数 |
| sortBy | string | ❌ | 排序字段，默认 SectionName |
| isDescending | bool | ❌ | 是否降序，默认 false |
| keyword | string | ❌ | 关键字模糊搜索（SectionName、PlantGradePrefix、Remark） |
| filters | string | ❌ | JSON 序列化的 FilterDescriptor 数组 |

#### GET /api/standard-work-day/{id}

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | ✅ | 记录 ID |

#### POST /api/standard-work-day/save

请求体（StandardWorkDayDto）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | ❌ | 0 时新增，> 0 时更新 |
| sectionName | string | ✅ | 工段名称 |
| plantGradePrefix | string? | ❌ | 牌号前缀，null=通用 |
| standardDays | double | ✅ | 标准天数 |
| remark | string? | ❌ | 备注 |

#### POST /api/standard-work-day/delete/{id}

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | int | ✅ | 要删除的记录 ID |

### 2.4 响应格式

统一返回 `ApiResponse<T>` 格式：

```json
{
  "success": true,
  "data": { ... },
  "message": null
}
```

### 2.5 请求/响应示例

#### 分页查询

```http
GET /api/standard-work-day/list?pageIndex=1&pageSize=10&sortBy=sectionname&isDescending=false
```

```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": 1,
        "sectionName": "冷轧拔",
        "plantGradePrefix": null,
        "standardDays": 2,
        "remark": "冷轧/冷拔"
      }
    ],
    "totalCount": 15,
    "pageIndex": 1,
    "pageSize": 10
  }
}
```

#### 保存

```http
POST /api/standard-work-day/save
Content-Type: application/json

{
  "id": 0,
  "sectionName": "测试工段",
  "plantGradePrefix": null,
  "standardDays": 1.5,
  "remark": "测试"
}
```

```json
{
  "success": true,
  "data": true
}
```

#### 删除

```http
POST /api/standard-work-day/delete/1
```

```json
{
  "success": true,
  "data": true
}
```

## 十、跨上下文调用接口

配置上下文提供三个字典查询方法供业务模块内部调用（非 API 端点，通过 DI 注入）：

### 10.1 GetStandardDaysMapAsync

```csharp
Task<Dictionary<string, double>> GetStandardDaysMapAsync(string? plantGrade)
```

- **用途**：获取工段名称 → 标准天数的映射字典
- **匹配规则**：按 SectionName 分组，优先取 PlantGradePrefix 精确匹配当前牌号，未找到则取通用（null）条目
- **调用方**：MaterialPlanService、MaterialPlanProcessGroupService、ProductionRecordService

### 10.2 GetDeliveryStateExtraDaysMapAsync

```csharp
Task<Dictionary<string, double>> GetDeliveryStateExtraDaysMapAsync()
```

- **用途**：获取交货状态枚举名 → 附加天数的映射字典（仅返回 PlantGradePrefix == null 的通用配置）
- **调用方**：MaterialPlanService、MaterialPlanProcessGroupService、ProductionRecordService

### 10.3 GetConfigMapAsync

```csharp
Task<Dictionary<string, decimal>> GetConfigMapAsync(string category)
```

- **用途**：获取指定分类下所有参数键 → 数值的映射字典
- **缓存策略**：每次 HTTP 请求独立加载（Service 为 Scoped 生命周期），修改配置后下一秒请求自动生效
- **调用方**：14 个业务 Service（详见 4.5 节）
