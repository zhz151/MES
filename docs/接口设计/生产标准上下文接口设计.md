# 生产标准上下文接口设计

**版本：V2.0**
**最后更新：2026-08-17**

---

## 一、概述

生产标准上下文提供 9 组 API 端点：标准号（StandardRegister）、牌号对照（GradeMapping）、标准牌号化学成分（GradeChemicalComposition）、牌号物理性能（GradePhysicalProperty）、子标准速览（SubStandardQuickView）、标准号检验项要求（StandardInspectionRequirement）、工厂检验项要求（FactoryInspectionRequirement）、工厂牌号化学成分（ChemicalComposition）、工厂牌号化分验证规则（ChemicalValidationRule）。所有接口统一返回 `ApiResponse<T>`。

**Base URL：** `/api`

**公共权限：** 牌号对照/标准牌号化学成分/牌号物理性能/子标准速览/标准号检验项要求等模块采用 `StandardRead`（查看）/ `StandardWrite`（创建/编辑），删除（DELETE）需 `Admin`；标准号（StandardRegister）控制器仅类级 `[Authorize]`，未按角色细分（仅需登录）

## 二、标准号 API（StandardRegister）

**Controller：** `MES.Api.Controllers.StandardRegister.StandardRegisterController`
**路由：** `api/standard-register`

### 2.1 端点列表

| 方法 | 路由 | 权限 | 返回类型 | 说明 |
|------|------|------|---------|------|
| GET | `api/standard-register/list` | 仅需登录（未按角色细分） | `ApiResponse<PagedResult<StandardRegisterDto>>` | 分页列表 |
| GET | `api/standard-register/{id}` | 仅需登录（未按角色细分） | `ApiResponse<StandardRegisterDto>` | 获取详情 |
| POST | `api/standard-register/save` | 仅需登录（未按角色细分） | `ApiResponse<int>` | 创建/更新（返回 Id，0=失败） |
| DELETE | `api/standard-register/delete/{id}` | 仅需登录（未按角色细分） | `ApiResponse<bool>` | 删除 |
| GET | `api/standard-register/all` | 仅需登录（未按角色细分） | `ApiResponse<List<StandardRegisterDto>>` | 获取全部（下拉选择用） |
| GET | `api/standard-register/resolve-name` | 仅需登录（未按角色细分） | `ApiResponse<string?>` | 根据标准号解析名称 |
| GET | `api/standard-register/filter-contexts` | 仅需登录（未按角色细分） | `ApiResponse<Dictionary<string, List<string>>>` | 筛选上下文 |
| GET | `api/standard-register/{id}/items` | 仅需登录（未按角色细分） | `ApiResponse<List<StandardRegisterItemDto>>` | 获取子项目列表 |
| POST | `api/standard-register/item/save` | 仅需登录（未按角色细分） | `ApiResponse<int>` | 保存子项目（返回 Id，0=失败） |
| POST | `api/standard-register/item/delete/{id}` | 仅需登录（未按角色细分） | `ApiResponse<bool>` | 删除子项目 |
| POST | `api/standard-register/cleanup-orphaned-items` | 仅需登录（未按角色细分） | `ApiResponse<int>` | 清理孤儿子项及重复项（返回删除条数） |
| POST | `api/standard-register/print-batch-file` | 仅需登录（未按角色细分） | `FileResult` (PDF) | 批量打印选中记录（返回 PDF 文件） |
| POST | `api/standard-register/print-all-file` | 仅需登录（未按角色细分） | `FileResult` (PDF) | 按搜索条件打印全部记录（返回 PDF 文件） |

### 2.2 筛选上下文

返回所有列的 DISTINCT 值：StandardLevel/ManufactureMethod/SteelType。

### 2.3 子项目保存说明

`SaveItemAsync` 返回新记录 Id（V1.5 从 bool 改为 int）。前端 `SaveAll` 先保存头拿到 `headerId`，再以此保存子项（`StandardRegisterId = headerId`），并将返回的 `itemId` 回写到 `item.Id`，防止双击保存重复创建。

### 2.4 AOP 配置

| 配置 | 值 |
|------|-----|
| 日志记录 | ✅ 全部操作记录 |
| 缓存策略 | 无 |
