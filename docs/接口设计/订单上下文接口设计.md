**版本：V2.5**

## 一、概述

本文档定义订单上下文的接口设计，包括枚举、DTO、API 端点和业务规则。

## 二、枚举定义

### 2.1 订单状态（SalesOrderStatus）

| 值 | 说明 |
|----|------|
| Pending | 待处理 |
| Confirmed | 已确认 |
| Cancelled | 已取消 |

### 2.2 客户状态（CustomerStatus）

| 值 | 说明 |
|----|------|
| Active | 启用 |
| Inactive | 停用 |

### 2.3 长度状态（LengthStatus）

| 值 | 说明 |
|----|------|
| Fixed | 定尺 |
| Range | 范围尺 |
| NonFixed | 非定尺 |

### 2.4 结算方式（SettlementMethod）

| 值 | 说明 |
|----|------|
| Weighing | 过磅 |
| WeighingNegative | 过磅-负 |
| Theoretical | 理算 |

### 2.5 制管类型（PipeManufacturingType）

| 值 | 说明 |
|----|------|
| SeamlessPipe | 无缝管 |
| WeldedPipe | 焊管 |

### 2.6 交货状态（DeliveryState）

| 值 | 说明 |
|----|------|
| SolutionAnnealedAndPickled | 固溶酸洗 |
| SolutionAnnealedAndPickledUTube | 固溶酸洗-U型管 |
| SolutionAnnealedAndPickledExternalPolished | 固溶酸洗-外抛光 |
| SolutionAnnealedAndPickledInternalPolished | 固溶酸洗-内抛光 |
| SolutionAnnealedAndPickledBothPolished | 固溶酸洗-内外抛光 |
| SolutionAnnealedAndPickledCoiled | 固溶酸洗-盘管 |
| Bright | 光亮 |
| BrightUTube | 光亮-U型管 |
| BrightCoiled | 光亮-盘管 |
| Hard | 硬态 |
| SolidSolutionStraightening | 固溶矫直 |

### 2.7 产品要求类型（RequirementType）

| 值 | 说明 |
|----|------|
| Normal | 常规 |
| Special | 特殊 |

## 四、API 端点

### 4.1 订单管理

| 方法 | 路由 | 权限 | 说明 |
|------|------|------|------|
| GET | /api/order/list | OrderStaff / OrderDirector / Admin | 分页查询订单列表（含技术要求状态、订单状态筛选） |
| GET | /api/order/{id} | OrderStaff / OrderDirector / Admin | 根据ID获取订单详情 |
| POST | /api/order | OrderDirector / Admin | 创建订单 |
| PUT | /api/order/{id} | OrderDirector / Admin | 更新订单 |
| POST | /api/order/{id}/save-all | OrderDirector / Admin | 批量保存（头+项次）：单事务完成订单头更新 + 全部项次增删改 |
| DELETE | /api/order/{id} | Admin | 删除订单（物理删除） |
| GET | /api/order/{id}/print | OrderStaff / OrderDirector / Admin | 打印单个订单（返回base64 PDF字符串） |
| POST | /api/order/print-batch | OrderStaff / OrderDirector / Admin | 批量打印选定订单（请求体: OrderPrintBatchRequest） |
| POST | /api/order/print-all | OrderStaff / OrderDirector / Admin | 按筛选条件打印全部订单（请求体: OrderPrintAllRequest） |
| GET | /api/order/{orderId}/requirements/print | OrderStaff / OrderDirector / Admin | 打印订单技术要求 |
| GET | /api/order/list-all | OrderStaff / OrderDirector / Admin | 获取全量订单列表 |
| GET | /api/order/filter-contexts | OrderStaff / OrderDirector / Admin | 获取筛选上下文 |
| GET | /api/order/by-number/{orderNo} | OrderStaff / OrderDirector / Admin | 按订单号查询 |
| POST | /api/order/refresh | OrderDirector / Admin | 刷新读模型（前端已无手动按钮，保留用于数据修复） |
| GET | /api/order/{id}/operation-logs | OrderStaff / OrderDirector / Admin | 获取订单操作日志（返回 `OperationLogDto` 列表，由基础设施统一管理） |

**查询参数（GET /api/order/list）：**

除通用分页/排序/关键词参数外，支持以下筛选参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| technicalStatus | string? | - | 技术要求状态筛选。可选值：`edited`（已编辑）、`notedited`（未编辑） |
| orderStatus | string? | - | 订单状态筛选。可选值为 `SalesOrderStatus` 枚举值：`Pending`（待处理）、`Confirmed`（已确认）、`Cancelled`（已取消） |

## 五、业务规则

### 5.1 订单号规则

| 项目 | 规则 |
|------|------|
| 生成方式 | 用户手动输入 |
| 固定格式 | 11位字符 |
| 唯一性校验 | 必须校验，不允许重复 |

### 5.2 订单状态流转规则

**状态定义：**

| 状态 | 英文 | 说明 |
|------|------|------|
| 待处理 | Pending | 订单未生效 |
| 已确认 | Confirmed | 订单已确认 |
| 已取消 | Cancelled | 订单取消 |

**状态流转规则：**

| 当前状态 | 允许变更到的状态 |
|----------|------------------|
| Pending | Confirmed, Cancelled |
| Confirmed | Cancelled |
| Cancelled | 无（终态） |

**状态变更权限：** Admin 和 OrderDirector 可修改

### 5.3 项次号规则

| 项目 | 规则 |
|------|------|
| 生成方式 | 系统自动生成 |
| 起始值 | 从 1 开始 |
| 递增规则 | 同一订单内依次递增 |
| 删除后处理 | 不重新排序，保留原项次号 |

### 5.4 理算重量计算规则

**公式：**
- 理算重量 = 密度 × 3.1416 × 壁厚有效值 × (外径有效值 - 壁厚有效值) × 米数 / 1000


**参数计算：**

| 参数 | 公式 | 说明 |
|------|------|------|
| 壁厚有效值 | 壁厚 - 0.5 × 壁厚负差 + 0.5 × 壁厚正差 | 考虑偏差后的有效壁厚 |
| 外径有效值 | 外径 - 0.5 × 外径负差 + 0.5 × 外径正差 | 考虑偏差后的有效外径 |
| 系数 | 3.1416 | π的近似值 |

**米数计算规则：**

| 长度状态 | 米数来源 | 公式 |
|----------|----------|------|
| Fixed（定尺） | 系统自动计算 | MaxLength × 支数 / 1000 |
| Range（范围尺） | 手工录入 | 用户输入的 Meters |
| NonFixed（非定尺） | 手工录入 | 用户输入的 Meters |

**边界处理：**

| 场景 | 处理规则 |
|------|----------|
| 计算结果为负数 | 设为 0 |
| 米数或支数为空 | 理算重量计算结果为 0 |
| 保留小数位数 | 2位 |

### 5.5 规格生成规则

| 项目 | 规则 |
|------|------|
| 格式 | {外径}*{壁厚} |
| 小数处理 | 保留原有小数位，不进行四舍五入取整 |

**示例：**

| 外径 | 壁厚 | 生成的规格 |
|------|------|-----------|
| 76 | 5 | 76*5 |
| 76 | 5.05 | 76*5.05 |
| 76.5 | 5.25 | 76.5*5.25 |

### 5.6 牌号对照规则

| 项目 | 规则 |
|------|------|
| 触发时机 | 用户选择 StandardGrade 时 |
| 自动填充字段 | PlantGrade（工厂牌号）、Density（密度） |
| 数据来源 | StandardGradeMapping 表 |
| 牌号不存在 | 拒绝创建订单，提示用户 |

### 5.7 长度验证规则

| 长度状态 | MinLength | MaxLength | 说明 |
|----------|-----------|-----------|------|
| Fixed（定尺） | 必填 > 0 | 等于 MinLength | 系统自动设置 |
| Range（范围尺） | 必填 > 0 | 必填 > 0 且 > MinLength | 用户输入 |
| NonFixed（非定尺） | 不需要 | 不需要 | - |

### 5.8 删除规则

**订单删除规则：**

| 订单状态 | 是否允许删除 | 说明 |
|----------|--------------|------|
| Pending（待处理） | ✅ 允许 | |
| Confirmed（已确认） | ✅ 允许 | |
| Cancelled（已取消） | ❌ 不允许 | 已取消的订单不能删除 |

**项次删除规则：**

| 项目 | 规则 |
|------|------|
| 删除方式 | 物理删除（使用 context.Remove()） |

**产品要求（ProductRequirement）删除规则：**

| 项目 | 规则 |
|------|------|
| 删除方式 | 随 OrderItem 级联物理删除 |
| 单独删除 | 禁止（API 调用会抛出业务异常） |

### 5.9 更新规则

| 订单状态 | 是否允许修改 | 说明 |
|----------|--------------|------|
| Pending（待处理） | ✅ 允许 | |
| Confirmed（已确认） | ✅ 允许 | |
| Cancelled（已取消） | ❌ 禁止 | 已取消的订单不能修改 |

### 5.10 级联删除规则

| 操作 | 级联范围 | 说明 |
|------|----------|------|
| 删除订单 | OrderItem + ProductRequirement | 订单物理删除时，所有项次和产品要求同步物理删除 |
| 删除项次 | ProductRequirement | 项次物理删除时，关联的产品要求同步物理删除 |

### 5.11 乐观并发控制

| 项目 | 规则 |
|------|------|
| 实现方式 | 使用 RowVersion 字段（SQL Server timestamp） |
| 冲突处理 | 抛出异常，提示用户刷新后重试 |

### 5.12 订单删除时自动清理工单与通知

- 当订单被物理删除时，系统自动执行以下操作：
  1. 物理删除该订单下的所有订单项次和产品要求
  2. 物理删除该订单下的所有工单
  3. 若有工单被清理，生成一条“订单删除通知”（记录订单号、清理工单数量）
- 该通知由工单模块负责展示和处理，订单模块仅负责生成。

## 七、错误码定义

| 错误码 | 说明 | 场景 |
|--------|------|------|
| 200 | 成功 | - |
| 400 | 业务错误 | 订单号已存在、客户不存在、牌号不存在等 |
| 401 | 未认证 | 未提供或提供无效的JWT |
| 403 | 无权限 | 角色权限不足 |
| 404 | 资源不存在 | 订单ID不存在 |
| 409 | 并发冲突 | 乐观并发控制冲突 |
| 500 | 系统错误 | 服务器内部错误 |

### 业务错误示例

| 错误消息 | 说明 |
|----------|------|
| 订单号必须为11位字符 | 订单号格式错误 |
| 订单号已存在 | 创建订单时订单号重复 |
| 客户不存在 | CustomerId无效 |
| 标准牌号无效 | StandardGrade 在牌号对照表中不存在 |
| 定尺时必须填写长度 | Fixed时MinLength为空 |
| 范围尺时必须填写最小长度和最大长度 | Range时MinLength或MaxLength为空 |
| 已取消的订单不能删除 | 尝试删除Cancelled状态的订单 |
| 已取消的订单不能修改 | 尝试修改Cancelled状态的订单 |
| 订单已被其他用户修改，请刷新后重试 | 乐观并发控制冲突 |
