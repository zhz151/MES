## 一、概述

本文档定义仓库上下文的接口设计，包括DTO、API端点、请求/响应示例、错误码等。

## 二、DTO定义

## 五、错误码定义

| 错误码 | 说明 | 场景 |
|--------|------|------|
| 200 | 成功 | - |
| 400 | 业务错误 | 出库数量超限、批次已冻结、参数校验失败等 |
| 401 | 未认证 | 未提供或提供无效的JWT |
| 403 | 无权限 | 角色权限不足 |
| 404 | 资源不存在 | 仓库/批次ID不存在 |
| 500 | 系统错误 | 服务器内部错误 |
