# 配置上下文详细设计

**版本：V2.0**
**最后更新：2026-07-08**

---

## 一、概述

配置上下文（Configuration Context）是系统支撑上下文，提供系统参数配置表的维护功能。包含八个参数表：工段工量天数（StandardWorkDays）、交态附加天数（StandardWorkDayDeliveryStates）、默认配置-系统参数（ConfigParameters）、规格日产预估（DailyOutputEstimates）、重点工段日产（DailyProductionCapacities）、工段日流转量（SectionFlowCategorySettings）、工位管理（Workstations）、员工管理（Employees），用于替代原有硬编码逻辑。

**功能定位：**
- 支撑级上下文，AdminOnly 权限
- 参数由管理员通过内联编辑页面动态维护
- 业务模块（批次/工单/用料计划/质量/仓库/订单等）通过 Service 层 DI 注入读取参数

**核心功能：**
1. 标准工量天数维护（StandardWorkDays）— 各工段生产天数基准
2. 交货状态附加天数维护（StandardWorkDayDeliveryStates）— 交货状态周期调整
3. 默认配置-系统参数维护（ConfigParameters）— 通用数值常量 EAV 管理
4. 日产能预估维护（DailyOutputEstimates）— 日产吨数基准，用于产能工量计算
5. 重点工段日产维护（DailyProductionCapacities）— 各重点工段日产能力（吨/天），用于工单总览产能负荷计算
6. 日流转量配置维护（SectionFlowCategorySettings）— 流转量分析预设参数
7. 工位管理维护（Workstations）— 扫码报工工位定义（Code→SectionName+EquipmentName+ReportType）
8. 员工管理维护（Employees）— 扫码报工和工资结算基础信息（工号/姓名/部门/岗位/工资结算模式）

**设计原则：**
- 查改一体表：所有参数在同一页面内联编辑，不采用独立编辑页
- 无业务校验：参数值由管理员自行保证正确性，系统不做复杂校验
- 实时生效：参数保存后，业务模块下一次计算时自动使用新值（Scoped 生命周期，每请求自动重载）

## 二、标准工量天数（StandardWorkDays）

### 2.1 页面路由

`/standard-work-days`

### 2.2 导航位置

参数表 → 生产-工段工量天数（AdminOnly）

### 2.3 功能说明

维护各工段在各条件下的标准生产天数，支持按牌号前缀覆盖。系统在以下场景使用本表替代原有硬编码：

| 原硬编码 | 现配置化 |
|---------|---------|
| `SectionDefs.GetStandardDays(sectionName, plantGrade)` | StandardWorkDays 表按 SectionName + PlantGradePrefix 匹配 |

### 2.4 页面字段（4列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 工段名称 | SectionDefs 常量 | ✅ | ✅ |
| 牌号前缀 | 如 "3"，空=通用 | ✅ | ❌ |
| 标准天数 | 浮点数（如 2.0、0.5） | ✅ | ✅ |
| 备注 | 文字说明 | ✅ | ❌ |

### 2.5 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 SectionName、PlantGradePrefix、Remark |
| 排序 | 默认按 SectionName 升序，支持全字段排序 |
| 筛选 | 支持通用筛选（MudExcelFilter） |

### 2.6 编辑模式

采用内联编辑模式（查改一体表）：
- 列表上方工具栏：搜索框 + 新建按钮 + 列显隐切换
- 行操作：编辑/保存/取消/删除按钮
- 编辑时直接修改行内字段值

## 三、交货状态附加天数（StandardWorkDayDeliveryStates）

### 3.1 页面路由

`/standard-work-day-delivery-states`

### 3.2 导航位置

参数表 → 生产-交态附加天数（AdminOnly）

### 3.3 功能说明

维护各交货状态对应的附加天数。DeliveryState 为空字符串表示默认配置，非空表示具体的交货状态枚举名。系统在以下场景使用本表替代原有硬编码：

| 原硬编码 | 现配置化 |
|---------|---------|
| `if (deliveryState != SolutionAnnealedAndPickled && deliveryState != Hard) totalDays += 4` | StandardWorkDayDeliveryStates 表按 DeliveryState 枚举名匹配 |

### 3.4 页面字段（4列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 交货状态 | 枚举名（空字符串=默认值） | ✅ | ✅ |
| 附加天数 | 浮点数 | ✅ | ✅ |
| 牌号前缀 | 预留，当前未使用 | ✅ | ❌ |
| 备注 | 文字说明 | ✅ | ❌ |

### 3.5 交货状态枚举显示

页面中交货状态列通过枚举值显示中文标签：

| 枚举值 | 中文标签 |
|--------|---------|
| （空字符串） | （默认值） |
| SolutionAnnealedAndPickled | 固溶酸洗 |
| SolutionAnnealedAndPickledAndSkinPassed | 固溶酸洗+平整 |
| SolutionAnnealedAndPickledAndColdDrawn | 固溶酸洗+冷拔 |
| BrightCoiled | 光亮-盘管 |
| Hard | 硬态 |

### 3.6 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 DeliveryState、Remark |
| 排序 | 默认按 DeliveryState 升序，支持全字段排序 |

注：前端未传递 filters 参数，暂不支持通用筛选。

### 3.7 编辑模式

同 StandardWorkDays，采用内联编辑模式。

## 四、默认配置-系统参数（ConfigParameters）

### 4.1 页面路由

`/config-parameters`

### 4.2 导航位置

参数表 → 默认配置-系统参数（AdminOnly）

### 4.3 功能说明

通用数值型业务参数配置管理页面，替代约 50+ 处硬编码业务数值常量。采用 EAV 模式（Category + ParamKey + ParamValue），支持任意分类扩展。

前端显示时通过 `CategoryDisplayMap` 将英文分类名映射为中文分组名（如 `MaterialPlanRatio` → `用料计划-比率`），并支持中文分类名搜索。

### 4.4 页面字段（4列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 参数分类 | 功能模块分组（显示中文，title 显示英文原值） | ✅ | ✅ |
| 参数键 | 分类下唯一键名 | ✅ | ✅ |
| 参数值 | decimal 数值 | ✅ | ✅ |
| 用途说明 | 参数用途描述 | ✅ | ❌ |

### 4.5 分类清单

| 中文分类 | 英文 Category | 包含键数 | 说明 |
|---------|---------------|---------|------|
| **用料计划-比率** | MaterialPlanRatio | 4 | 固定单/非固定单的成品率、库存率（FixedFinishRatio 等） |
| **用料计划-状态阈值** | MaterialPlanStatus | 7 | 用料计划满足状态判定阈值（FixedPartial/FixedSatisfied/NonFixedPartial/NonFixedSatisfied/SmallBatchMaxQty/SmallBatchSatisfiedRate/SupplySatisfiedRate） |
| **用料计划-尺寸公差** | DimensionTolerance | 4 | 库存匹配尺寸公差系数（OD/WT 上下限） |
| **用料计划-长度默认值** | LengthDefault | 2 | 单重计算长度(4500)、管长(6000) |
| **用料计划-返工比率** | ReworkRatio | 8 | 改制库存匹配比例系数（空拔/少道次 OD/WT 上下限等） |
| **批次-加工折扣** | ProcessingDiscount | 2 | 原料比率(1.1)、组批折扣率(0.025) |
| **批次-生产阈值** | ProductionThreshold | 5 | 冷轧完成率、检验/有效录入上下限 |
| **产能排程-时间桶** | DateBucket | 5 | 订单总览时间桶阈值（15/30/45/60/90天） |
| **仓库-完成阈值** | WarehouseThreshold | 6 | 入库完工比率/偏差、委外/采购完工比率及偏差、委外回收比率 |
| **交期排程-工单天数** | WorkOrderDays | 2 | 工单缓冲天数、检验固定天数 |
| **交期排程-紧急度阈值** | UrgencyThreshold | 4 | 紧急度分级天数阈值（A+急/A急/B顺/C顺） |
| **合同-重量校验** | ContractWeight | 2 | 合同重量校验上下限(0.94~1.06) |
| **质量-工序跳号** | SequenceJump | 1 | 检验工序最大跳步(7) |
| **通用-默认值** | DefaultValue | 4 | 工序周期(25)、标准周期(3)、批次最大序号(9999)、荒管完成率(0.92) |

### 4.6 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 Category（支持中文分类名自动映射为英文）、ParamKey、Remark |
| 排序 | 默认按 Category 升序，支持全字段排序 |
| 筛选 | 支持通用筛选（MudExcelFilter） |

### 4.7 编辑模式

同 StandardWorkDays，采用内联编辑模式 + 新增行支持。

### 4.8 缓存策略

ConfigParameter 的数据读取采用 Service 层 `_configMaps` 字典缓存（Scoped 级别）。
由于所有 Service 注册为 `AddScoped`（每次 HTTP 请求创建新实例），`_configMaps` 仅在同一请求内缓存重复查询。
修改参数后，下一次请求会自动加载新值。

## 六、日流转量配置（SectionFlowCategorySettings）

### 6.1 页面路由

`/section-flow-category-settings`

### 6.2 导航位置

参数表 → 生产-工段日流转量（AdminOnly）

### 6.3 功能说明

管理生产段流转量分析所需的预设参数。数据实体属于**配置上下文**（SectionFlowCategorySetting + SectionFlowCategoryItem），API 由 `SectionFlowCategorySettingsController`（配置上下文）独立提供，前端管理页面在配置上下文菜单下。原与排程分析混用的 `SectionFlowAnalysisService` 已于 2026-07-08 拆分，CRUD 职责移交 `SectionFlowCategoryService`。

| 排序号 | DisplayOrder（int） | ✅ |
| 操作 | 保存/取消/删除/新增 | - |

### 6.5 展开/折叠实现

- 使用自定义展开机制（非 MudTable RowDetailTemplate，因其与自定义按钮交互存在兼容性问题）
- `_expandedIds` HashSet 跟踪展开状态
- 展开区域通过 `@foreach` 在主表下方独立渲染，左侧 3px #1565C0 蓝色边框 + #f8f9fe 背景
- 子表使用 RenderTreeBuilder 在 `RenderChildTable()` 方法中构建

### 6.6 编辑模式

- 主表内联编辑：`_editingIds`（HashSet）跟踪编辑行，`_editCache`（Dictionary）暂存编辑值
- 子表内联编辑：`_itemEditingIds` + `_itemEditCache` 完全独立于主表，避免状态冲突
- 编辑状态仅保存本行，不涉及批量提交
- 物理删除（EF Core Remove，非软删除）

### 6.7 关联查询

| 类型 | 说明 |
|------|------|
| 搜索 | 不支持（数据量小，仅14行） |
| 排序 | 默认按 CategoryCode 升序 |
| 筛选 | 不支持 |
| 持久化 | 无 PageState/ColumnPrefs（数据量小，简化实现） |

### 6.8 数据源

- 实体：`MES.Data/Entities/Configuration/SectionFlowCategorySetting.cs`、`SectionFlowCategoryItem.cs`
- Service：`MES.Services/Configuration/SectionFlowCategoryService.cs`（Configuration 上下文，V2.1 起从 SectionFlowAnalysisService 独立拆分）
- API 端点详见计划排程上下文接口设计 §7.2
- 前端 Blazor Service：`MES.Blazor/Services/Configuration/SectionFlowCategoryService.cs`

## 七、日产能预估（DailyOutputEstimates）

### 7.1 页面路由

`/daily-output-estimates`

### 7.2 导航位置

参数表 → 生产-规格日产预估（AdminOnly）

### 7.3 功能说明

维护各成品外径区间对应的日产能力（吨/天），用于工单模块中产能工量（CapacityWorkDays）的计算。

**计算逻辑：**
- CapacityWorkDays = CEILING(主号汇总总重量(kg) - 已完成批次有效成品重量(kg)) / 1000 / 日产估算(吨/天)
- 匹配规则：取 MinOuterDiameter &lt;= 实际外径 的最大值对应的 DailyOutputTons

**数据特点：**
- 约 5-10 行数据，按 MinOuterDiameter 降序排序
- 典型数据：外径 ≤ 20mm 日产 15 吨，外径 ≤ 40mm 日产 30 吨，外径 ≤ 60mm 日产 50 吨等

### 7.4 页面字段（3列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 最小外径 | 外径下限（mm），匹配规则：≤ 实际外径的最大值 | ✅ | ✅ |
| 日产(吨/天) | 日产能力 | ✅ | ✅ |
| 备注 | 文字说明 | ✅ | ❌ |

### 7.5 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 Remark |
| 排序 | 默认按 MinOuterDiameter 降序，支持全字段排序 |
| 筛选 | 支持通用筛选（MudExcelFilter） |

### 7.6 编辑模式

同 StandardWorkDays，采用内联编辑模式（查改一体表）+ 新增行支持。

## 十、跨上下文引用关系

### 10.1 工量计算引用（StandardWorkDays + StandardWorkDayDeliveryStates）

```
批次上下文（ProductionRecordService）
  ├── RemainingWorkDays 计算 → StandardWorkDays.GetStandardDaysMapAsync()
  └── TotalWorkDays 计算   → StandardWorkDays + StandardWorkDayDeliveryStates

工单上下文（MaterialPlanService）
  ├── StandardCycle 计算（荒管采购/圆棒穿孔）→ StandardWorkDays + StandardWorkDayDeliveryStates
  └── 用料计划 upsert StandardProcessCycle（已移除）

工单上下文（MaterialPlanProcessGroupService）
  └── 工序组保存时 StandardCycle 重算 → StandardWorkDays + StandardWorkDayDeliveryStates
```

### 10.1.1 GetStandardDaysMapAsync 匹配规则

```
按 SectionName 分组：
  1. 找 PlantGradePrefix 与当前 plantGrade 前缀精确匹配的条目
  2. 未找到则取 PlantGradePrefix == null 的通用条目
  3. 仍找不到则返回 0
```

### 10.1.2 GetDeliveryStateExtraDaysMapAsync 匹配规则

```
仅返回 PlantGradePrefix == null 的通用配置：
  1. 先找 DeliveryState 精确匹配当前交货状态枚举名的条目
  2. 未找到则取 DeliveryState == "" 的默认条目
```
