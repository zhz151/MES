# 配置上下文详细设计

**版本：V2.4**
**最后更新：2026-08-15**

---

## 一、概述

配置上下文（Configuration Context）是系统支撑上下文，提供系统参数配置表的维护功能。包含十一个参数表：工段工量天数（StandardWorkDays）、交态附加天数（StandardWorkDayDeliveryStates）、默认配置-系统参数（ConfigParameters）、规格日产预估（DailyOutputEstimates）、重点工段日产（DailyProductionCapacities）、工段日流转量（SectionFlowCategorySettings）、工位管理（Workstations）、员工管理（Employees）、枚举显示配置（EnumDisplayDefinitions）、字典值配置（DictValueDefinitions）、工序组定义（ProcessDefinitions），用于替代原有硬编码逻辑。

**功能定位：**
- 支撑级上下文，AdminOnly 权限
- 参数由管理员通过内联编辑页面动态维护
- 业务模块（批次/工单/用料计划/质量/仓库/订单等）通过 Service 层 DI 注入读取参数
- **显示层参数化（V2.3 新增）**：枚举显示配置/字典值配置/工序组定义三表驱动前端下拉/列表/打印的中文显示名、排序与启停（枚举可改名排序、字典可隐藏加值、工序组可启停改默认工段），后端 API 启动注入 + 前端 MainLayout 加载 display-map/options-map 即时生效

**核心功能：**
1. 标准工量天数维护（StandardWorkDays）— 各工段生产天数基准（含 SectionKey/DisplayOrder/IsEnabled 展示层动态化）
2. 交货状态附加天数维护（StandardWorkDayDeliveryStates）— 交货状态周期调整
3. 默认配置-系统参数维护（ConfigParameters）— 通用数值常量 EAV 管理
4. 日产能预估维护（DailyOutputEstimates）— 日产吨数基准，用于产能工量计算
5. 重点工段日产维护（DailyProductionCapacities）— 各重点工段日产能力（吨/天），用于工单总览产能负荷计算
6. 日流转量配置维护（SectionFlowCategorySettings）— 流转量分析预设参数
7. 工位管理维护（Workstations）— 扫码报工工位定义（Code→SectionName+EquipmentName+ReportType）
8. 员工管理维护（Employees）— 扫码报工和工资结算基础信息（工号/姓名/部门/岗位/工资结算模式）
9. 枚举显示配置维护（EnumDisplayDefinitions）— 枚举值中文显示名与排序（不可加值）
10. 字典值配置维护（DictValueDefinitions）— 字典值显示名/排序/启停（可隐藏加值）
11. 工序组定义维护（ProcessDefinitions）— 工序组中文名/启停/排序/冷轧标记/默认工段

**设计原则：**
- 查改一体表：所有参数在同一页面内联编辑，不采用独立编辑页
- 无业务校验：参数值由管理员自行保证正确性，系统不做复杂校验
- 实时生效：参数保存后，业务模块下一次计算时自动使用新值（Scoped 生命周期，每请求自动重载）

## 二、标准工量天数（StandardWorkDays）

### 2.1 页面路由

`/standard-work-days`

### 2.2 导航位置

参数表 → 生产-工段工量天数（AdminOnly）

### 2.3 功能说明

维护各工段在各条件下的标准生产天数，支持按牌号前缀覆盖。系统在以下场景使用本表替代原有硬编码：

| 原硬编码 | 现配置化 |
|---------|---------|
| `SectionDefs.GetStandardDays(sectionName, plantGrade)` | StandardWorkDays 表按 SectionName + PlantGradePrefix 匹配 |

### 2.4 页面字段（7列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 工段名称 | SectionDefs 常量（可改名，槽位复用启新工段） | ✅ | ✅ |
| SectionKey | 稳定 Key（对应 SectionDefs 常量名，如 ColdRollDraw），程序识别工段用，不受改名影响 | 只读 | ❌ |
| DisplayOrder | 显示顺序（升序，1 排最前），1~999 | ✅ | ✅ |
| IsEnabled | 是否启用（启用/隐藏，false 时界面不显示该工段） | ✅ | ✅ |
| 牌号前缀 | 如 "3"，空=通用 | ✅ | ❌ |
| 标准天数 | 浮点数（如 2.0、0.5），0.1~365 | ✅ | ✅ |
| 备注 | 文字说明 | ✅ | ❌ |

> **展示层动态化：** 工段列表列、各计划页工段列由 `GetEnabledSectionsAsync`（enabled-sections 端点，IsEnabled=true、SectionKey 去重、通用行优先、DisplayOrder 升序）驱动，前端 `LoadSectionColsAsync` 加载，失败/空 fallback 到 SectionDefs 26 预置超集。

### 2.5 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 SectionName、PlantGradePrefix、Remark |
| 排序 | 默认按 SectionName 升序，支持全字段排序 |
| 筛选 | 支持通用筛选（MudExcelFilter） |

### 2.6 编辑模式

采用内联编辑模式（查改一体表）：
- 列表上方工具栏：搜索框 + 新建按钮 + 列显隐切换
- 行操作：编辑/保存/取消/删除按钮
- 编辑时直接修改行内字段值

## 三、交货状态附加天数（StandardWorkDayDeliveryStates）

### 3.1 页面路由

`/standard-work-day-delivery-states`

### 3.2 导航位置

| 原硬编码 | 现配置化 |
|---------|---------|
| `if (deliveryState != SolutionAnnealedAndPickled && deliveryState != Hard) totalDays += 4` | StandardWorkDayDeliveryStates 表按 DeliveryState 枚举名匹配 |

### 3.4 页面字段（4列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 交货状态 | 枚举名（空字符串=默认值） | ✅ | ✅ |
| 附加天数 | 浮点数 | ✅ | ✅ |
| 牌号前缀 | 预留，当前未使用 | ✅ | ❌ |
| 备注 | 文字说明 | ✅ | ❌ |

### 3.5 交货状态枚举显示

页面中交货状态列通过枚举值显示中文标签：

| 枚举值 | 中文标签 |
|--------|---------|
| （空字符串） | （默认值） |
| SolutionAnnealedAndPickled | 固溶酸洗 |
| SolutionAnnealedAndPickledAndSkinPassed | 固溶酸洗+平整 |
| SolutionAnnealedAndPickledAndColdDrawn | 固溶酸洗+冷拔 |
| BrightCoiled | 光亮-盘管 |
| Hard | 硬态 |

### 3.6 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 DeliveryState、Remark |
| 排序 | 默认按 DeliveryState 升序，支持全字段排序 |

注：前端未传递 filters 参数，暂不支持通用筛选。

### 3.7 编辑模式

同 StandardWorkDays，采用内联编辑模式。

## 四、默认配置-系统参数（ConfigParameters）

### 4.1 页面路由

`/config-parameters`

### 4.2 导航位置

参数表 → 默认配置-系统参数（AdminOnly）

### 4.3 功能说明

通用数值型业务参数配置管理页面，替代约 50+ 处硬编码业务数值常量。采用 EAV 模式（Category + ParamKey + ParamValue），支持任意分类扩展。

前端显示时按种子数据 `CategoryDisplay` 字段展示中文分组名（如 `MaterialPlanRatio` → `工单-用料计划比率`），并支持中文分类名搜索。

### 4.4 页面字段（4列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 参数分类 | 功能模块分组（显示中文，title 显示英文原值） | ✅ | ✅ |
| 参数键 | 分类下唯一键名 | ✅ | ✅ |
| 参数值 | decimal 数值 | ✅ | ✅ |
| 用途说明 | 参数用途描述 | ✅ | ❌ |

### 4.5 分类清单

| 中文分类 | 英文 Category | 包含键数 | 说明 |
|---------|---------------|---------|------|
| **工单-用料计划比率** | MaterialPlanRatio | 4 | 固定单/非固定单的成品率、库存率（FixedFinishRatio 等） |
| **用料计划-状态阈值** | MaterialPlanStatus | 7 | 用料计划满足状态判定阈值（FixedPartial/FixedSatisfied/NonFixedPartial/NonFixedSatisfied/SmallBatchMaxQty/SmallBatchSatisfiedRate/SupplySatisfiedRate） |
| **用料计划-尺寸公差** | DimensionTolerance | 4 | 库存匹配尺寸公差系数（OD/WT 上下限） |
| **工单-长度默认值** | LengthDefault | 2 | 单重计算长度(4500)、管长(6000) |
| **工单-改制系数** | ReworkRatio | 8 | 改制库存匹配比例系数（空拔/少道次 OD/WT 上下限等） |
| **工单-用料计划执行容差** | MaterialPlanTolerance | 6 | 对外/对内仓库/对内生产执行容差上下限（ExternalLower 等） |
| **批次-加工损耗率** | ProcessingDiscount | 2 | 原料比率(1.1)、组批折扣率(0.025) |
| **批次-生产阈值** | ProductionThreshold | 5 | 冷轧完成率、检验/有效录入上下限 |
| **产能排程-时间桶** | DateBucket | 5 | 订单总览时间桶阈值（15/30/45/60/90天） |
| **仓库-完成阈值** | WarehouseThreshold | 6 | 入库完工比率/偏差、委外/采购完工比率及偏差、委外回收比率 |
| **交期排程-工单天数** | WorkOrderDays | 2 | 工单缓冲天数、检验固定天数 |
| **交期排程-紧急度阈值** | UrgencyThreshold | 4 | 紧急度分级天数阈值（A+急/A急/B顺/C顺） |
| **合同-重量校验** | ContractWeight | 2 | 合同重量校验上下限(0.94~1.06) |
| **质量-工序跳号** | SequenceJump | 1 | 检验工序最大跳步(7) |
| **质量-NCR触发阈值** | NcrThreshold | 6 | 返整/让步接收/报废的触发支数及百分比（ReworkCount 等） |
| **通用-默认值** | DefaultValue | 4 | 默认工艺周期(22)、标准周期(3)、批次最大序号(9999)、荒管完成率(0.92) |

### 4.6 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 Category（支持中文分类名自动映射为英文）、ParamKey、Remark |
| 排序 | 默认按 Category 升序，支持全字段排序 |
| 筛选 | 支持通用筛选（MudExcelFilter） |

### 4.7 编辑模式

同 StandardWorkDays，采用内联编辑模式 + 新增行支持。

### 4.8 缓存策略

ConfigParameter 的数据读取采用 Service 层 `_configMaps` 字典缓存（Scoped 级别）。
由于所有 Service 注册为 `AddScoped`（每次 HTTP 请求创建新实例），`_configMaps` 仅在同一请求内缓存重复查询。
修改参数后，下一次请求会自动加载新值。

## 六、日流转量配置（SectionFlowCategorySettings）

### 6.1 页面路由

`/section-flow-category-settings`

### 6.2 导航位置

参数表 → 生产-工段日流转量（AdminOnly）

### 6.3 功能说明

管理生产段流转量分析所需的预设参数。数据实体属于**配置上下文**（SectionFlowCategorySetting），API 由 `SectionFlowCategorySettingsController`（配置上下文）独立提供，前端管理页面在配置上下文菜单下。原与排程分析混用的 `SectionFlowAnalysisService` 已于 2026-07-08 拆分，CRUD 职责移交 `SectionFlowCategoryService`。

每行一个流转类别，全量加载不分页；类别包含的 (工序组,工段,产类) 组合由组合归类表（CombinationGroups）承载。

### 6.4 页面字段

**页面字段（7列）：**

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 流转类别 | CategoryName（唯一，重复被拒） | ✅ | ✅ |
| 排序号 | DisplayOrder（升序，1 排最前） | ✅ | ✅ |
| 日产设定 | DailyProductionTarget（吨） | ✅ | ❌ |
| 偏少天数值 | LowerLimitDays | ✅ | ❌ |
| 过多天数值 | UpperLimitDays | ✅ | ❌ |
| 备注 | Remark | ✅ | ❌ |
| 操作 | 保存/取消/删除/新增 | - | - |

### 6.5 编辑模式

- 内联编辑：`_editingIds`（HashSet）跟踪编辑行，`_editCache`（Dictionary）暂存编辑值
- 编辑状态仅保存本行，不涉及批量提交
- 物理删除（EF Core Remove，非软删除），删除类别级联删除其组合归类行

### 6.6 关联查询

| 类型 | 说明 |
|------|------|
| 搜索 | 不支持（数据量小，全量加载） |
| 排序 | 默认按 DisplayOrder 升序 |
| 筛选 | 不支持 |
| 持久化 | 无 PageState/ColumnPrefs（数据量小，简化实现） |

### 6.7 数据源

- 实体：`MES.Data/Entities/Configuration/SectionFlowCategorySetting.cs`
- Service：`MES.Services/Configuration/SectionFlowCategoryService.cs`（Configuration 上下文，V2.1 起从 SectionFlowAnalysisService 独立拆分）
- API 端点详见计划排程上下文接口设计 §7.2
- 前端 Blazor Service：`MES.Blazor/Services/Configuration/SectionFlowCategoryService.cs`

## 七、日产能预估（DailyOutputEstimates）

### 7.1 页面路由

`/daily-output-estimates`

### 7.2 导航位置

参数表 → 生产-规格日产预估（AdminOnly）

### 7.3 功能说明

维护各成品外径区间对应的日产能力（吨/天），用于工单模块中产能工量（CapacityWorkDays）的计算。

**计算逻辑：**
- CapacityWorkDays = CEILING(主号汇总总重量(kg) - 已完成批次有效成品重量(kg)) / 1000 / 日产估算(吨/天)
- 匹配规则：取 MinOuterDiameter &lt;= 实际外径 的最大值对应的 DailyOutputTons

**数据特点：**
- 约 5-10 行数据，按 MinOuterDiameter 降序排序
- 典型数据：外径 ≤ 20mm 日产 15 吨，外径 ≤ 40mm 日产 30 吨，外径 ≤ 60mm 日产 50 吨等

### 7.4 页面字段（3列）

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 最小外径 | 外径下限（mm），匹配规则：≤ 实际外径的最大值 | ✅ | ✅ |
| 日产(吨/天) | 日产能力 | ✅ | ✅ |
| 备注 | 文字说明 | ✅ | ❌ |

### 7.5 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖 Remark |
| 排序 | 默认按 MinOuterDiameter 降序，支持全字段排序 |
| 筛选 | 支持通用筛选（MudExcelFilter） |

### 7.6 编辑模式

同 StandardWorkDays，采用内联编辑模式（查改一体表）+ 新增行支持。

| PicklingOutRecord | 出缸完工 | 酸洗出缸记录 |
| SectionOutsource | 工段委外 | 委外发出记录 |
| OutsourceRecovery | 委外回收 | 委外收回记录 |
| ProcessInspection | 过程检验 | 过程检验记录 |
| FinalInspection | 成品检验 | 成品检验记录 |
| MaterialReceiveCheck | 成检到料 | 成检到料记录 |

### 8.4 页面字段

| 列 | 说明 | 内联编辑 | 必填 |
|---|------|---------|------|
| 工位编码 | 工位唯一代码（二维码内容） | ✅ | ✅ |
| 工位名称 | 名称（解释性，可为空） | ✅ | ❌ |
| 设备名称 | 对应设备，无设备时可为空 | ✅ | ❌ |
| 工段 | 所属工段（对应 SectionDefs 常量） | ✅ | ✅ |
| 报工模板类型 | 决定扫码后使用哪个表单模板（下拉选择8种） | ✅ | ✅ |
| 启用 | 是否启用 | ✅ | ❌ |

### 8.5 关联查询

| 类型 | 说明 |
|------|------|
| 关键字搜索 | 覆盖工位编码、工位名称、设备名称、工段、报工模板类型 |
| 排序 | 支持全字段排序，默认按 Code 升序 |
| 筛选 | 支持通用筛选（MudExcelFilter） |

### 8.6 编辑模式

采用内联编辑模式（查改一体表），同其他参数表。MudSelect 下拉选择报工模板类型（8个固定选项）。

## 十三、跨上下文引用关系

### 13.1 工量计算引用（StandardWorkDays + StandardWorkDayDeliveryStates）

```
批次上下文（ProductionRecordService）
  ├── RemainingWorkDays 计算 → StandardWorkDays.GetStandardDaysMapAsync()
  └── TotalWorkDays 计算   → StandardWorkDays + StandardWorkDayDeliveryStates

工单上下文（MaterialPlanService）
  ├── StandardCycle 计算（荒管采购/圆棒穿孔）→ StandardWorkDays + StandardWorkDayDeliveryStates
  └── 用料计划 upsert StandardProcessCycle（已移除）

工单上下文（MaterialPlanProcessGroupService）
  └── 工序组保存时 StandardCycle 重算 → StandardWorkDays + StandardWorkDayDeliveryStates
```

### 13.1.1 GetStandardDaysMapAsync 匹配规则

```
按 SectionName 分组：
  1. 找 PlantGradePrefix 与当前 plantGrade 前缀精确匹配的条目
  2. 未找到则取 PlantGradePrefix == null 的通用条目
  3. 仍找不到则返回 0
```

### 13.1.2 GetDeliveryStateExtraDaysMapAsync 匹配规则

```
仅返回 PlantGradePrefix == null 的通用配置：
  1. 先找 DeliveryState 精确匹配当前交货状态枚举名的条目
  2. 未找到则取 DeliveryState == "" 的默认条目
```

### 13.2 业务数值常量引用（ConfigParameters）

ConfigParameter 被约 16 个 Service 引用，通过 `IConfigParameterService.GetConfigMapAsync(category)` 获取参数映射：

```
批次上下文：
  ├── BatchService             → DefaultValue.BatchMaxSequence
  ├── ProductionRecordService  → SequenceJump / WarehouseThreshold / ProcessingDiscount
  └── SectionOutsourceService  → WarehouseThreshold.OutsourceRecoveryRatio

工单上下文：
  ├── WorkOrderService         → MaterialPlanRatio / MaterialPlanStatus
  ├── WorkOrderExecutionService→ DefaultValue / MaterialPlanStatus
  ├── WorkOrderListSummaryRefreshService → MaterialPlanRatio / DefaultValue / MaterialPlanStatus
  ├── MaterialPlanService      → MaterialPlanStatus / DefaultValue / DimensionTolerance / LengthDefault / ReworkRatio
  └── MaterialPlanProcessGroupService →（引用 StandardWorkDays + DeliveryStates）

仓库上下文：
  └── InventorySyncService     → WarehouseThreshold.SubcontractCompleteRatio

物料上下文：
  ├── PurchaseOrderService     → WarehouseThreshold
  └── SubcontractOrderService  → WarehouseThreshold

质量上下文：
  ├── ProcessInspectionService → SequenceJump.MaxJump
  └── NcrService → NcrThreshold

订单上下文：
  └── OrderService             → ContractWeight

计划排程：
  └── ProductionOverviewService→ ProcessingDiscount / DailyProductionCapacities / DateBucket

数据修复：
  └── DataFixService           → WarehouseThreshold.OutsourceRecoveryRatio
```
