# 生产标准上下文详细设计

**版本：V1.9**
**最后更新：2026-08-17**

---

## 一、概述

生产标准上下文（Production Standard Context）提供标准牌号及材料性能数据的维护功能。包含九个子模块：标准号（StandardRegister）、牌号对照（StandardGradeMapping）、标准牌号化学成分（GradeChemicalComposition）、工厂牌号化学成分（ChemicalComposition）、工厂牌号化分验证规则（ChemicalValidationRule）、牌号物理性能（GradePhysicalProperty）、子标准速览（SubStandardQuickView）、标准号检验项要求（StandardInspectionRequirement）、工厂检验项要求（FactoryInspectionRequirement）。

**功能定位：**
- 基础数据上下文，StandardRead/StandardWrite 权限
- 数据通过内联编辑列表页维护，也支持 DataExchange 批量导入导出
- 订单模块通过 StandardNo 弱引用标准号，通过 StandardGrade+StandardGradeCategory 关联化学成分/物理性能

**核心功能：**
1. 标准号管理 — 标准号头+子项目（检验项目）维护
2. 牌号对照管理 — 标准牌号与工厂牌号映射关系维护
3. 标准牌号化学成分管理 — 按 StandardGrade+StandardGradeCategory 维度维护 15 种元素含量
4. 工厂牌号化学成分管理 — 按 PlantGrade 维度维护工厂牌号的化学成分参考值
5. 工厂牌号化分验证规则管理 — 按 PlantGrade 维度配置各化学元素上下限验证规则（含公式"X×C%"）
6. 牌号物理性能管理 — 按 StandardGrade+StandardGradeCategory 维度维护物理性能参数
7. 子标准速览 — 按标准号列出各检验项目对应的引用标准/快速参考信息
8. 标准号检验项要求 — 按标准号集中管理各检验项目的分类/强制/取样/范围/标准要求
9. 工厂检验项要求 — 按标准号维护工厂实际检验流程的强制性等级（必检/按需等），作为订单技术要求默认值的数据源

**设计原则：**
- GradeChemicalComposition/GradePhysicalProperty 不设 FK 约束，通过 (StandardGrade, StandardGradeCategory) 纯逻辑关联
- ChemicalComposition/ChemicalValidationRule 按 PlantGrade 维度，与 StandardGradeMapping 弱关联
- 所有列表页使用 ServerData + ExcelFilter 模式
- 内联编辑为主，批量创建为辅

| POST | `api/standard-register/print-all-file` | 全部打印标准号（PDF文件） |

### 2.7 保存机制说明

**SaveAsync / SaveItemAsync 返回类型：** 从 `bool` 改为 `int`（V1.5），返回新记录 Id（0 表示失败）。

**目的：** 解决子项目序号重复问题：
- 创建模式：先保存头拿到 Id，再以此保存子项（`StandardRegisterId` 正确关联）
- 编辑模式：`SaveItemAsync` 回写新 Id 到 `item.Id`，防止双击保存重复创建
- 保存后自动重新加载子项目列表，确保前端数据与数据库一致

**冗余清理：** `CleanupOrphanedItemsAsync()` 删除三类脏数据：
1. `StandardRegisterId = 0` 的孤儿子项
2. 主表已不存在的子项（FK 引用失效）
3. 同 `StandardRegisterId + SeqNo` 的重复项（保留最小 Id）

**设计说明：**
- StandardNo 唯一，每标准号一条记录
- 与 StandardRegister.StandardNo 弱引用（无 FK 约束）
- **与 StandardInspectionRequirement（标准号检验项要求）的区别：** 增加 6 项（PMI检验/表检/尺寸/内窥/水下气压/端口着色），列顺序按工厂实际检验流程排列（第 3-12 列）
- **用途：** 作为订单技术要求默认值的数据源——ProductRequirement 按 OrderItem.StandardNo（去空格规范化）匹配，字段映射 4 值枚举 `InspectionRequirementStage`：含"必检"→**FinalOnly「终」**（仅正式成检，默认）、"按需"/"-"/空→**None「-」**（不要求，`MapFactoryRequirement`）；液压检验仅定尺（LengthStatus=Fixed）按标准号带出，非定尺→None；**2026-08-17 迁移 `20260816175222_FactoryInspectionRequirementPmiMandatory` 将存量 PmiInspection 48 条全改"必检"（与表检+尺寸一致，使预填 PMI 带出「终」）**
- **创建默认值（仅创建页预填）：** 表检+尺寸="必检"；PMI检验+内窥+水下气压+端口着色="按需"；其余自由文本（MudTextField）
