# 质量证明书详细设计（V2.4）

**版本**：V2.4
**最后更新**：2026-08-01

---

## 一、概述

### 1.1 功能定位

质量证明书（质保书）是钢管出厂时随货附带的**质量凭证文件**，证明该批次产品符合相关标准或客户要求的质量指标。

采用 **"订单+项次"** 模式——主表存公共信息，附表存每批次的仓库信息 + 化学成分 + 检验结果。

| 项目 | 说明 |
|------|------|
| 归属上下文 | 质量管理 |
| 优先级 | 🔴 发货刚需，上线阻塞项 |
| 使用角色 | 质量人员（出具）、仓管（随货附寄）、客户（验收） |
| 核心原则 | **快照模式**——签发后数据冻结，修改原始检测数据不影响已签发的质保书 |

### 1.2 与现有模块的关系

```
检测表（数据源）                   质保书                        打印输出
────────────────────────────────────────────────────────────────────────────────────
ChemicalAnalysis    ──┐
FurnaceRegistration ──┤   编辑时拉取实测值 → 调整 → 保存
TensileTest         ──┤           ↓
HardnessTest        ──┤    Certificate.Items（4类数据快照）
GrainSizeTest       ──┤           ↓
MetallographicTest  ──┤    产品标准+钢牌号 → 查标准要求值（打印时）
FlaringTest         ──┤           ↓
FlatteningTest      ──┤    CertificatePrintHelper → PDF
IntergranularCorrosionTest ─┤           ↓
PittingCorrosionTest ──┤    第3类+第4类：按标准配置列显隐
FinalInspection     ──┘
```

**关键设计**：
- 质保书不存 FK 指向原始检测表，只存最终值的副本（快照）
- 化学成分和成品检验的**标准要求值**不存实体，打印时按"产品标准 + 钢牌号"查询
- 第3类（成品检验）+ 第4类（理化检测）打印时支持列显隐
- **V2.1 变更**：保存采用**一次性写入**（CreateAsync 直接接收完整 DTO），避免两阶段保存导致的 SeqNo/ID 映射问题；子表 Group 2~4 均为可编辑组件

## 二、实体设计

### 2.1 主表 Certificate（类似"订单"）

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | int (PK) | 自增主键 |
| `CertificateNo` | string | **证明书编号** = 订单号 + "-01"，如 SO20240714001-01 |
| `IssueDate` | DateTime | **签发日期** |
| `CustomerName` | string? | 客户名称 |
| `ProductStandard` | string? | 产品标准，如 GB/T 8162-2018 |
| `ProductName` | string? | 产品名称 |
| `DeliveryStatus` | string? | 交货状态 |
| `Remark` | string? | 备注 |
| 审计字段 | | CreatedTime / CreatedBy / UpdatedTime / UpdatedBy |

**编号规则**：`{订单号}-{2位流水}`，流水从01开始，每次发货加1。
例：订单 SO20240714001 第一次发货 → `SO20240714001-01`，第二次 → `SO20240714001-02`

### 2.2 附表 CertificateItem（类似"项次"，双实体模式）

每条记录 = **该批次的一次出库明细**，含仓库信息 + 化学成分 + 4类检验结果。继承 BaseEntity，有独立审计。

#### 2.2.1 基础字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | int (PK) | 自增主键 |
| `CertificateId` | int (FK) | → Certificate |
| `SeqNo` | int | 序号，从1开始 |

#### 2.2.2 第1类：仓库信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `InventoryBatchNo` | string? | **库存批次号（仓库批次号）** |
| `ProductionBatchNo` | string? | 生产批次 |
| `HeatNo` | string? | 炉号 |
| `SteelGrade` | string? | 钢牌号 |
| `Specification` | string? | 规格 |
| `LengthDesc` | **string?** | **长度描述**，如"8000-9000"（用string兼容范围值） |
| `Quantity` | int? | 支数 |
| `Meters` | decimal? | 米数 |
| `Weight` | decimal? | 重量(kg) |

> **长度取值规则**：从仓库数据取最小长度（`MinLength`）和最大长度（`MaxLength`），两者相等取任一值，不等取 `"{MinLength}-{MaxLength}"`。该逻辑在前端 `FillSubItemsFromSelection` 中完成。

#### 2.2.3 第2类：化学成分（仅存实测值）

| 字段 | 类型 |
|------|------|
| `ChemC` | decimal? |
| `ChemSi` | decimal? |
| `ChemMn` | decimal? |
| `ChemP` | decimal? |
| `ChemS` | decimal? |
| `ChemNi` | decimal? |
| `ChemCr` | decimal? |
| `ChemMo` | decimal? |
| `ChemCu` | decimal? |
| `ChemN` | decimal? |
| `ChemNb` | decimal? |
| `ChemTi` | decimal? |
| `ChemFe` | decimal? |
| `ChemAl` | decimal? |
| `ChemW` | decimal? |
| `ChemPREN` | decimal? |

> **标准要求值不存实体**，打印时按 `ProductStandard + SteelGrade` 从标准数据表查询，与实测值并列展示。

#### 2.2.4 第3类：成品检验结果（仅存检验结果）

| 字段 | 类型 | 说明 |
|------|------|------|
| `InspPMI` | string? | PMI检验，如"逐支合格" |
| `InspVisual` | string? | 表检 |
| `InspDimension` | string? | 尺寸 |
| `InspEndoscopy` | string? | 内窥 |
| `InspHydro` | string? | 水压 |
| `InspUnderwaterPneumatic` | string? | 水下气压 |
| `InspEddyCurrent` | string? | 涡流 |
| `InspUltrasonic` | string? | 超声波 |
| `InspPortDye` | string? | 端口着色 |

> **标准要求值不存实体**。打印时按 `ProductStandard + SteelGrade` 查询每个项目的明细要求（如"水压"的压力值+保压时间），与检验结果并列展示。

#### 2.2.5 第4类：理化检测结果（支持2个试样值）

**室温拉伸（4字段 × 2样 = 8值）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `TensileStrength_1` | decimal? | 抗拉强度(MPa) 试样1 |
| `TensileStrength_2` | decimal? | 抗拉强度(MPa) 试样2 |
| `YieldRp02_1` | decimal? | 屈服强度Rp0.2(MPa) 试样1 |
| `YieldRp02_2` | decimal? | 屈服强度Rp0.2(MPa) 试样2 |
| `YieldRp10_1` | decimal? | 屈服强度Rp1.0(MPa) 试样1 |
| `YieldRp10_2` | decimal? | 屈服强度Rp1.0(MPa) 试样2 |
| `Elongation_1` | decimal? | 延伸率(%) 试样1 |
| `Elongation_2` | decimal? | 延伸率(%) 试样2 |

**硬度（1字段 × 2样 = 2值）：**

| 字段 | 类型 |
|------|------|
| `Hardness_1` | string? |
| `Hardness_2` | string? |

**晶粒度（1字段 × 2样 = 2值）：**

| 字段 | 类型 |
|------|------|
| `GrainSize_1` | string? |
| `GrainSize_2` | string? |

**金相（1字段 × 2样 = 2值）：**

| 字段 | 类型 |
|------|------|
| `FerriteContent_1` | decimal? |
| `FerriteContent_2` | decimal? |

**扩口/压扁/晶间腐蚀/点腐蚀（1字段 × 1样 = 1值）：**

| 字段 | 类型 |
|------|------|
| `FlaringResult` | string? |
| `FlatteningResult` | string? |
| `IntergranularResult` | string? |
| `PittingResult` | string? |

## 三、数据流

### 3.1 编辑时拉取数据

```
用户选择订单头（4字段去重：订单号/客户/产品标准/交货状态）
                ↓
从待发货查询（PendingDeliveryQuery）加载该订单的库存批次
                ↓
选择批次 → 填充到子表（仓库信息来源于 PendingDeliveryItemDto）
                ↓
点击"生成"按钮 → 后端 AutoFillInspectionDataAsync
  ① 按炉号（FurnaceNumber）查 FurnaceRegistration 填充化学成分
  ② 按生产批号（BatchNo）查 FinalInspection 填充成品检验结果
  ③ 理化检测（8项）按生产编号（FurnaceNo）+ 试样号（SampleNo）匹配：
     ┌─────────────────────┬──────────────┬──────────────┐
     │ 检验类型             │ 取值字段       │ 映射规则       │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 室温拉伸 TensileTest │ TensileStrength     │ SampleNo=1 → _1  │
     │                     │ YieldStrengthRp02    │ SampleNo=2 → _2  │
     │                     │ YieldStrengthRp1     │                │
     │                     │ Elongation          │                │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 硬度 HardnessTest   │ HardnessValue        │ SampleNo=1 → _1  │
     │                     │                     │ SampleNo=2 → _2  │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 晶粒度 GrainSizeTest│ GrainSizeGrade       │ SampleNo=1 → _1  │
     │                     │                     │ SampleNo=2 → _2  │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 金相 Metallographic │ FerriteContent       │ SampleNo=1 → _1  │
     │                     │                     │ SampleNo=2 → _2  │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 扩口 FlaringTest    │ Judgment             │ 任一试样，单值    │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 压扁 FlatteningTest │ Judgment             │ 任一试样，单值    │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 晶间腐蚀 Intergr.   │ Judgment             │ 任一试样，单值    │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 点腐蚀 PittingTest  │ Judgment             │ 任一试样，单值    │
     └─────────────────────┴──────────────┴──────────────┘
                ↓
用户可手动编辑 Group 2~4 各字段
                ↓
提交保存 → 一次性 CreateAsync（含全部 46 字段数据）
  → Items 写入 CertificateItem 表（快照落地）
```

> **关键变更（V2.1）**：原为两阶段保存（CreateAsync 查 InventoryBatch 建项 + UpdateAsync 补检查数据），现改为一次性保存。CreateAsync 直接使用前端传入的完整 DTO 数据映射实体，保持 SeqNo 一致，避免 ID 映射脱节。

### 3.2 打印时读取

```
打印请求
  → 查 Certificate（含 Items）
  → 按 ProductStandard + SteelGrade 查标准要求值（化学成分/成品检验各项要求）
  → 通用 CertificatePrintHelper 渲染
     ├── 基本信息区
     ├── 仓库信息区
     ├── 化学成分表（实测值 + 标准要求值）
     ├── 成品检验表（按标准配置列显隐）
     ├── 理化检测表（按标准配置列显隐）
     └── 签章区
  → 输出 PDF
```

## 四、打印设计

### 4.1 打印模板策略

采用**通用模板**模式，不按标准系列分多个 Helper。QuestPDF 版式固定（标题区 + 基本信息区 + 各 Section 表格 + 签章区），标准差异由**列显隐配置**控制。

```
一个通用 Helper：
  CertificatePrintHelper.cs
  └── 读配置 → 决定第3类（成品检验）+ 第4类（理化检测）的哪些列显示
```

### 4.2 列显隐配置

每个标准系列定义第3类和第4类的显示列：

```json
{
  "CertificateTemplate_GB": {
    "hideColumns": {
      "category3": ["InspEddyCurrent", "InspUltrasonic"],   // GB 标准不显示涡流和超声
      "category4": []                                         // 全显示
    }
  },
  "CertificateTemplate_ASTM": {
    "hideColumns": {
      "category3": [],                                         // 全显示
      "category4": ["IntergranularResult"]                    // ASTM 不显示晶间腐蚀
    }
  }
}
```

配置存放位置：**ConfigParameter EAV 模式**。

### 4.3 标准要求值查询（打印时）

化学成分和成品检验各项目的**标准要求值**不在实体中存储，打印时通过 Service 查询：

```csharp
// 伪代码
var standardRequirements = await _standardService.GetRequirementsAsync(
    productStandard: certificate.ProductStandard,
    steelGrade: item.SteelGrade,
    category: "Chemical"  // 或 "Inspection"
);
// 返回：{ "C": "≤0.15", "Si": "≤0.75", "水压": "10MPa/5s", ... }
```

### 4.4 证书版本管理

> ⚠️ **规划中，尚未实现**：以下 Status→Voided 作废及修订号 `-R1`/`-R2` 方案尚未在代码中实现（Certificate 实体无 Status 字段）。

证书签发后如需修改，不走"修改"，而是重新签发为新版本：

- 原证书 Status → Voided（作废）
- 创建新 CertificateNo，在原号后加 `-R1`、`-R2`（Revision）
- 复制原 Items 后可调整

**关键说明：**

- **产品名称自动匹配**：通过 StandardRegister 标准号映射，支持去空白容错（如 "GB/T13296-2023" 匹配 "GB/T 13296-2023"）
- **子表 Group 2~4 均支持手动编辑**：自动填充后用户可微调各值
- **保存为一次性请求**：CreateAsync 接收完整 DTO（含 46 字段），直接写入 CertificateItem 表
- **自动填充逻辑**：按炉号匹配化学成分（FurnaceRegistration），按生产批号匹配成品检验（FinalInspection）；理化检测（8项）按**生产编号+试样号**匹配——室温拉伸/硬度/晶粒度/金相按 SampleNo=1→_1、SampleNo=2→_2 分别填入值，扩口/压扁/晶间腐蚀/点腐蚀取任一试样的 Judgment 填入单值字段
