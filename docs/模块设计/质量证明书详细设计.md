# 质量证明书详细设计

> 版本：V2.6（2026-09-04）
> 状态：**已实施完成**。质量证明书（质保书）= 钢管出厂随货质量凭证，采用「订单+项次」双实体快照模式（Certificate + CertificateItem）：编辑时按炉号/生产批号/生产编号+试样号从 FurnaceRegistration、FinalInspection 及理化 8 类检测表拉取实测值，一次性 CreateAsync 写入快照（避免两阶段保存 SeqNo/ID 映射问题），标准要求值不落库、打印时按 产品标准+钢牌号 查询。打印已实现：QuestPDF 通用模板（CertificatePrintHelper）+ 版式 CertificatePrintSetting + 列布局 CertificatePrintColumnDefinition 两张配置表驱动列显隐/顺序/列宽，A4 横向每页固定 4 行（不足补空行、标准值参照行每页重复）、中英文双语版式；列表页打印选中（print-file）与打印列表（print-list-file）。证书版本管理（Status→Voided 作废 + 修订号 -R1/-R2）规划中尚未实现。

---

## 一、概述

### 1.1 功能定位

质量证明书（质保书）是钢管出厂时随货附带的**质量凭证文件**，证明该批次产品符合相关标准或客户要求的质量指标。

采用 **"订单+项次"** 模式——主表存公共信息，附表存每批次的仓库信息 + 化学成分 + 检验结果。

| 项目 | 说明 |
|------|------|
| 归属上下文 | 质量管理 |
| 优先级 | 🔴 发货刚需，上线阻塞项 |
| 使用角色 | 质量人员（出具）、仓管（随货附寄）、客户（验收） |
| 核心原则 | **快照模式**——签发后数据冻结，修改原始检测数据不影响已签发的质保书 |

### 1.2 与现有模块的关系

```
检测表（数据源）                   质保书                        打印输出
────────────────────────────────────────────────────────────────────────────────────
FurnaceRegistration ──┤   编辑时拉取实测值 → 调整 → 保存
TensileTest         ──┤           ↓
HardnessTest        ──┤    Certificate.Items（4类数据快照）
GrainSizeTest       ──┤           ↓
MetallographicTest  ──┤    产品标准+钢牌号 → 查标准要求值（打印时）
FlaringTest         ──┤           ↓
FlatteningTest      ──┤    CertificatePrintHelper → PDF
IntergranularCorrosionTest ─┤           ↓
PittingCorrosionTest ──┤    3 张明细表：按 CertificatePrintColumnDefinition 配置列显隐
FinalInspection     ──┘
```

**关键设计**：
- 质保书不存 FK 指向原始检测表，只存最终值的副本（快照）
- 化学成分和成品检验的**标准要求值**不存实体，打印时按"产品标准 + 钢牌号"查询
- 3 张明细表（物料信息/化学成分/检验检测）打印时按**打印列布局配置表**控制列显隐/顺序/列宽
- 保存采用**一次性写入**（CreateAsync 直接接收完整 DTO），避免两阶段保存导致的 SeqNo/ID 映射问题；子表 Group 2~4 均为可编辑组件
- 打印功能已实现（QuestPDF 通用模板 + 版式/列布局两张配置表 + 每页固定 4 行 + 中英文双语版式），详见「四、打印设计」

## 二、实体设计

### 2.1 主表 Certificate（类似"订单"）

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | int (PK) | 自增主键 |
| `CertificateNo` | string | **证明书编号** = 订单号 + "-01"，如 SO20240714001-01 |
| `IssueDate` | DateTime | **签发日期** |
| `CustomerName` | string? | 客户名称 |
| `ProductStandard` | string? | 产品标准，如 GB/T 8162-2018 |
| `ProductName` | string? | 产品名称 |
| `DeliveryStatus` | string? | 交货状态 |
| `Remark` | string? | 备注 |
| 审计字段 | | CreatedTime / CreatedBy / UpdatedTime / UpdatedBy |

**编号规则**：`{订单号}-{2位流水}`，流水从01开始，每次发货加1。
例：订单 SO20240714001 第一次发货 → `SO20240714001-01`，第二次 → `SO20240714001-02`

### 2.2 附表 CertificateItem（类似"项次"，双实体模式）

每条记录 = **该批次的一次出库明细**，含仓库信息 + 化学成分 + 4类检验结果。继承 BaseEntity，有独立审计。

#### 2.2.1 基础字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `Id` | int (PK) | 自增主键 |
| `CertificateId` | int (FK) | → Certificate |
| `SeqNo` | int | 序号，从1开始 |

#### 2.2.2 第1类：仓库信息

| 字段 | 类型 | 说明 |

## 三、数据流

### 3.1 编辑时拉取数据

```
用户选择订单头（4字段去重：订单号/客户/产品标准/交货状态）
                ↓
从订单成品（实时库存）待发货查询（PendingDeliveryQuery）加载该订单的库存批次
                ↓
选择批次 → 填充到子表（仓库信息来源于 PendingDeliveryItemDto）
                ↓
点击"生成"按钮 → 后端 AutoFillInspectionDataAsync
  ① 按炉号（FurnaceNumber）查 FurnaceRegistration 填充化学成分
  ② 按生产批号（BatchNo）查 FinalInspection 填充成品检验结果
  ③ 理化检测（8项）按生产编号（FurnaceNo）+ 试样号（SampleNo）匹配：
     ┌─────────────────────┬──────────────┬──────────────┐
     │ 检验类型             │ 取值字段       │ 映射规则       │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 室温拉伸 TensileTest │ TensileStrength     │ SampleNo=1 → _1  │
     │                     │ YieldStrengthRp02    │ SampleNo=2 → _2  │
     │                     │ YieldStrengthRp1     │                │
     │                     │ Elongation          │                │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 硬度 HardnessTest   │ HardnessValue        │ SampleNo=1 → _1  │
     │                     │                     │ SampleNo=2 → _2  │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 晶粒度 GrainSizeTest│ GrainSizeGrade       │ SampleNo=1 → _1  │
     │                     │                     │ SampleNo=2 → _2  │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 金相 Metallographic │ FerriteContent       │ SampleNo=1 → _1  │
     │                     │                     │ SampleNo=2 → _2  │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 扩口 FlaringTest    │ Judgment             │ 任一试样，单值    │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 压扁 FlatteningTest │ Judgment             │ 任一试样，单值    │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 晶间腐蚀 Intergr.   │ Judgment             │ 任一试样，单值    │
     ├─────────────────────┼──────────────┼──────────────┤
     │ 点腐蚀 PittingTest  │ Judgment             │ 任一试样，单值    │
     └─────────────────────┴──────────────┴──────────────┘
                ↓
用户可手动编辑 Group 2~4 各字段
                ↓
提交保存 → 一次性 CreateAsync（含全部 46 字段数据）
  → Items 写入 CertificateItem 表（快照落地）
```

> 保存采用一次性写入：CreateAsync 直接使用前端传入的完整 DTO 数据映射实体，保持 SeqNo 一致，避免两阶段保存（先建项、后补检查数据）导致的 ID 映射脱节。

### 3.2 打印时读取

```
打印请求（POST api/certificate/print-file，Body=Id 集合）
  → 查 Certificate（含 Items）
  → 加载版式配置 CertificatePrintSettings（Key→Value）+ 列布局配置 CertificatePrintColumnDefinitions
  → 按 ProductStandard + SteelGrade 查标准要求值（化学成分/成品检验/理化各项要求）
  → 通用 CertificatePrintHelper 渲染
     ├── 页眉：公司 Logo/名称/地址/联系方式 + 标题（中英双语）
     ├── 置顶行：证明书编号（左） + 签发日期（右对齐，中英双语）
     ├── 基本信息区（4 字段：客户名称/产品标准/产品名称/交货状态，双语）
     ├── 物料信息表（8 列）
     ├── 化学成分表（16 列，含每页重复的「标准值」参照行）
     ├── 检验检测表（21 列 = 成品检验 9 + 理化检测 11，含标准值参照行）
     ├── 页脚：说明文字 + 备注/盖章（中英）/检验员/工程师两行签字区
  → 每页固定 RowsPerPage=4 行数据（不足补占位空行），超过自动分页
  → 输出 PDF
```

> 明细表列显隐/顺序/列宽来自 `CertificatePrintColumnDefinition` 配置表（锚点 BlockKey+FieldKey）；`#` 序号列为固定列，不参与配置。

## 四、打印设计

### 4.1 打印模板策略

采用**通用模板**模式（QuestPDF Mode A，`CertificatePrintHelper.cs`），不按标准系列分多个 Helper。版式固定（页眉 + 基本信息 + 3 张明细表 + 页脚），标准差异与版式细节由**两张配置表**控制：

| 配置表 | 作用 | 锚点 |
|--------|------|------|
| `CertificatePrintSetting` | 版式配置（企业信息/标题/页脚文字/字体字号/区块间距）键值对 | Key（唯一） |
| `CertificatePrintColumnDefinition` | 列布局配置（3 张明细表每个字段的显隐/顺序/列宽/中英文名） | BlockKey + FieldKey |

打印链路：Controller 加载两张配置表 → `CertificatePrintHelper` 按配置渲染（详见 §3.2）。

**A4 横向**，margin 20。**每页固定 `RowsPerPage=4` 行数据**：数据 ≤4 行补占位空行（保留边框、序号与内容为空），>4 行自动分页并沿用页眉/页脚；化学/检验表「标准值」参照行每页重复；仅第一页含基本信息，续页从明细表开始。

**中英文双语版式**：区块标题（中文 + 英文小号）、字段标签（中英并列）、数据值（"合格 Qualified"、交货状态中英并列、标准值行"标准值 Std. Value"）均为白底黑字。

### 4.2 版式配置表（CertificatePrintSetting）

Key/Value 键值对（`DisplayName` 显示名、`Remark` 说明），默认值与模板硬编码值一致，`CertificatePrintKeys` 常量定义全部键。分组：

| 分组 | 键示例 |
|------|--------|
| 页眉企业信息 | CompanyName/CompanyNameEn/CompanyAddress/CompanyAddressEn/CompanyContact/CompanyLogoPath |
| 页眉标题 | HeaderTitle/HeaderTitleEn/HeaderFontFamily/HeaderFontSize |
| 内容字号 | PageFontSize/BasicInfoLabelFontSize/BasicInfoValueFontSize/SectionTitleFontSize/MaterialTableFontSize/ChemistryTableFontSize/InspectionTableFontSize/TableHeaderFontSizeDelta/**SectionSpacing**（区块间距，三处共用） |
| 页脚 | FooterStatement/FooterRemark/SealText/SealTextEn/InspectorText/SignerText |
| 页脚字号 | FooterStatementFontSize/FooterTextFontSize |

> 打印设置对话框「打印版式」Tab 编辑，默认值与真库实际值一致（由种子迁移幂等 upsert 写入）。

### 4.3 列布局配置表（CertificatePrintColumnDefinition）

3 张明细表每个打印字段一行：`BlockKey`（BasicInfo/Material/Chemistry/Inspection）+ `FieldKey` + `Label`（中文）+ `LabelEn`（英文，可空）+ `Visible`（显隐）+ `ColumnIndex`（区块内顺序）+ `ColumnWeight`（列宽权重）。`#` 序号列为固定列，不参与配置。

| 区块 | 字段数 | 说明 |
|------|--------|------|
| BasicInfo（基本信息） | 4 | 客户名称/产品标准/产品名称/交货状态（不走表格） |
| Material（物料信息） | 8 | 生产批号/炉号/牌号/规格/长度/支数/米数/重量 |
| Chemistry（化学成分） | 16 | 元素 + C~W 15 个元素 |
| Inspection（检验检测） | 20 | 成品检验 9 + 理化检测 11，合并为一张表（配置字段数 20，不含标准值参照行；打印时含参照行共 21 列，见 §3.2） |

> 打印设置对话框「字段布局」Tab 编辑（显隐开关/英文列名/列宽权重/上移下移调整顺序）。

### 4.4 标准要求值查询（打印时）

化学成分和成品检验各项目的**标准要求值**不在实体中存储，打印时通过 Service 查询：

```csharp
// 伪代码
var standardRequirements = await _standardService.GetRequirementsAsync(
    productStandard: certificate.ProductStandard,
    steelGrade: item.SteelGrade,
    category: "Chemical"  // 或 "Inspection"
);
// 返回：{ "C": "≤0.15", "Si": "≤0.75", "水压": "10MPa/5s", ... }
```

**关键说明：**

- **产品名称自动匹配**：通过 StandardRegister 标准号映射，支持去空白容错（如 "GB/T13296-2023" 匹配 "GB/T 13296-2023"）
- **子表 Group 2~4 均支持手动编辑**：自动填充后用户可微调各值
- **保存为一次性请求**：CreateAsync 接收完整 DTO（含 46 字段），直接写入 CertificateItem 表
- **自动填充逻辑**：按炉号匹配化学成分（FurnaceRegistration），按生产批号匹配成品检验（FinalInspection）；理化检测（8项）按**生产编号+试样号**匹配——室温拉伸/硬度/晶粒度/金相按 SampleNo=1→_1、SampleNo=2→_2 分别填入值，扩口/压扁/晶间腐蚀/点腐蚀取任一试样的 Judgment 填入单值字段
