# 成检计件详细设计

> 版本：V1.3（2026-09-04）
> 状态：**已实施完成（2026-09-03，类别 + 维档两表 + 试算 match-price + 专用批量导入/导出全落地）**。与生产计件（《生产计件详细设计.md》）同构但自成体系：**无「工段/工序/产类/作业阶段」四键约束**，类别直接以**成检项目（InspectionItem）单键定位**；维度域在生产的 7 维上换 2 维（删断切率/定尺、增长度状态/检验支数）得 8 维。迁移 `20260902183812_AddPieceRateFinalInspectionCategoryTables` 已 apply 真库（建两表 + 过滤唯一索引 + FK 级联）。**V1.2（09-04）**：试算 match-price 在结算单价外补**整行模拟计件工资**（金额折算抽 `PieceRateAmountHelper` 共享单源，结算/试算同口径）。**V1.3（09-04）**：模拟测算 UI 改为**按真实成检记录点选计价**（全局任意跨期记录）；记录→计价请求映射抽 `FinalInspectionMatchRequestMapper` 单源，成检结算采集与按记录试算共用，杜绝双通道口径漂移。

## 0. 目标与背景

成检（成品检验，水压/表检/超声波/涡流等）岗位计件此前冻结删除（旧单表删除时划出、日后再建）。本期独立重建：

- 与生产计件彻底分表：定位键是**成检项目**而非工段×工序×产类×作业阶段；
- 生产/成检共用的三个**不可动摇规则**沿用：①计价 = 类别基准价 × 各命中档系数连乘，**不存在例外价/绝对价**；②调价=停用旧类别 + 新建新类别（工资流水快照防追溯漂移）；③结算数量折算沿用 `PieceRateUnitKeys.QuantityDimension`。
- 差异点：类别间**不做覆盖禁交集**（不同成检项目天然互斥，仅「同项目启用唯一」一条约束）。

## 1. 领域模型总览

```
成检计件类别 = 成检项目(必选·单选·InspectionItem 9 项)
            + 基准价(必填) + 结算单位(必填) + 启停 + 备注
     │  1
     └─ 维度档（0..n，整组替换）  区间维：外径 / 壁厚 / 长度 / 检验支数(整数)
                                 等值维：长度状态 / 特殊牌号 / 特殊制造状态 / 特殊设备号
```

**键来源**：
- 成检项目：`MES.Core.Enums.InspectionItem`（9 项：PMI检验/表检/尺寸/内窥/水压/水下气压/涡流/超声波/端口着色）；
- 结算单位：`PieceRateUnitKeys`（复用生产）；
- 长度状态：`MES.Core.Enums.LengthStatus`（Fixed 定尺 / Range 范围尺 / NonFixed 非定尺）；
- 特殊牌号：`StandardGradeMapping.PlantGrade` 工厂牌号（等值补充）；
- 特殊制造状态：`PieceRateStateKeys`（等值补充）；
- 特殊设备号：报工 `EquipmentName` 设备号文本等值匹配（与生产同口径，暂未规范到设备表）。
- 维度键常量：`MES.Core/Constants/PieceRateInspectionDimensionKeys.cs`（`All[]` 顺序 = 外径/壁厚/长度/检验支数/长度状态/特殊牌号/特殊制造状态/特殊设备号；`IsInterval` 判区间维、`IsValueDimension` 判等值维、`ToChinese` 显示）。

## 2. 数据模型

### 2.1 PieceRateFinalInspectionCategory —— 成检计件类别（主表）

| 列 | 类型 | 说明 |
|---|---|---|
| Id | int PK | |
| ItemKey | nvarchar(30) | 成检项目（InspectionItem 枚举名，中英归一后落库英文） |
| BasePrice | decimal(18,4) | 基准价，必填，>0 |
| Unit | nvarchar(20) | 结算单位，必填（PieceRateUnitKeys） |
| IsActive | bit | 启用/停用 |
| Remark | nvarchar(200)? | 备注 |

继承 BaseEntity。**过滤唯一索引 `UK_FinalInspectionCategory_Item_Active`（(ItemKey) WHERE IsActive=1）**：同一成检项目同时仅一条启用类别；停用历史可多条并存（与生产「禁交集」在成检被「同项目启用唯一」取代）。

### 2.2 PieceRateFinalInspectionCategoryTier —— 类别维度档（子表）

| 列 | 类型 | 说明 |
|---|---|---|
| Id | int PK | |
| CategoryId | int FK | 所属类别（级联删，`IX_FinalInspectionTier_Category`） |
| DimensionKey | nvarchar(30) | 8 维（§4），键见 `PieceRateInspectionDimensionKeys` |
| RangeText | nvarchar(100)? | 区间原文（如 `>54`、`41-54`）或等值取值的 Key 冗余副本 |
| MinValue / MaxValue | decimal(10,2)? | 区间维数值边界（外径/壁厚/长度） |
| MinInt / MaxInt | int? | 检验支数维整数边界 |
| MatchValue | nvarchar(100)? | 等值维取值英文 Key |
| Ratio | decimal(18,6) | 加价系数（命中即乘；默认 1） |
| IsActive | bit | 启用/停用 |

继承 BaseEntity。**关键**：基准价只在类别上；维档行只存系数。结算单价 = 类别.BasePrice × 命中行 Ratio 连乘。类别更新 = 档行**整组替换**（旧行全删再插新）。

## 3. 类别定义规则

- **成检项目**：必选、单选、中英容忍（输入中文如「超声波」服务端 `EnumHelper.TryParse<InspectionItem>` 归一为枚举名落库）。
- **同项目启用唯一**：保存启用类别前服务端 `EnsureNoDuplicateActiveItemAsync` 预检 + DB 过滤唯一索引兜底；停用类别不与任何启用冲突，可多条并存。**类别之间不存在跨项目覆盖冲突**（不同项目天然互斥）。
- 类别更新整组替换档行；停用旧类别可再建新启用类别（同 Id 稳定更新亦可直接改基准）。

## 4. 维度档规则

| 维度 | 键 | 形态 | 匹配 |
|---|---|---|---|
| 外径 | OuterDiameter | 区间 | 数值落档 |
| 壁厚 | WallThickness | 区间 | 数值落档 |
| 长度 | Length | 区间 | 数值落档（**量纲 mm**）；**全长度状态参与**：Fixed=实际定尺长，Range/NonFixed 取数缺省按 6000 折算 |
| 检验支数 | InspectionCount | **整数区间** | 整数落档（MinInt/MaxInt） |
| 长度状态 | LengthStatus | 等值 | Fixed/Range/NonFixed（中英容忍：定尺→Fixed） |
| 特殊牌号 | SpecialGrade | 等值 | PlantGrade 等值命中 |
| 特殊制造状态 | SpecialState | 等值 | 状态 Key 等值命中 |
| 特殊设备号 | SpecialDevice | 等值 | EquipmentName 等值命中 |

- ⚠️ **长度档量纲 = mm**（真库档位 1500~16000，对应 1.5m~16m 管）。范围尺/非定尺批没有真实单支长，取数端按业务规约折算 **6000mm** 参与命中（2026-09-03 拍板「两者都要」）；当前真库 6000 落在 5001-7500 主档（系数 1.0）——**调整长度档位须先评估对范围尺/非定尺单价影响**。
- 类别下未配置的维度 = 系数 1，不参与（按实际档行自适应）；等值档未设/未命中 = 1。
- 区间档校验：同维启用行两两判定。**十进制区间**边界点相切（`41-54` 与 `>54`）= 合法邻接；**检验支数整数区间**共享边界整数即重叠拒存（`1-10` 与 `10-100` 冲突），邻接高档必须从低档末值+1 起（`1-10` 后接 `11-100`）。
- ⚠️ **整数档勿用开区间 `>N`/`<N`**：`PieceRateRangeParser` 对开区间按闭端点解析（`>10`→min=10），与相邻闭带共享整数会判重叠。需表达「N 以上」时写闭区间 `{N+1}-9999`（与 CutFile 定尺带 `1-2`/`9-9999` 改写约定一致）。
- 等值档同维取值去重（`OrdinalIgnoreCase`，中英归一后判重）。

## 5. 匹配算法（试算 / 将来结算共用）

```
输入：成检记录 r { ItemKey(成检项目), LengthStatus, OD, WT, LEN, 检验支数Count,
                   PlantGrade, EquipmentName, SpecialState, WeightKg(可选·元/吨模拟金额用) }
  LEN 取数规约：LengthStatus=Fixed → 实际定尺长(mm)；Range/NonFixed → 缺省 6000(mm)

1. 候选类别 = Category WHERE ItemKey == r.ItemKey AND IsActive
   → 同项目启用唯一保护下命中数 ≤ 1；>1 数据违例防御性 BusinessException。
   0 条 → null（未定价）。

2. 对候选类别启用的维档按维度分组，每维找命中的档行：
   - 区间维：数值/整数落入 Min/Max → 命中（若同维多条命中——数据重叠残留——取区间最窄 SpanWidth）；
   - 等值维：请求取值归一英文 Key 后与 MatchValue OrdinalIgnoreCase 等值命中。
   未配置的维 / 未命中 = 系数 1，跳过。

3. 单价 = 类别.BasePrice × Π(各命中维.Ratio)；返回命中明细（维度中文/档值/系数）。

4. 整行模拟计件工资 = `PieceRateAmountHelper.AmountForUnit(单价, 结算单位, WeightKg, 检验支数, LEN)`
   单源（2026-09-04，结算采集器同用）：元/吨=kg/1000×价 / 元/千米=支×mm/1e6×价 / 元/支=支数×价 / 元/头→null。
   缺对应数量（元/吨缺重量、元/千米缺支数或长度、元/支缺支数）→ SimulatedAmount=null。
   LEN 兜底同 Step2 前：Range/NonFixed 空长度由 `DefaultTrialLengthMm` 补 6000。
```

试算端点 POST `match-price` 即完整实现：命中单价 + 整行模拟工资一并返回（`SimulatedAmount`）；工资结算取数由 `PieceRateCollector` 走 `PieceRateMatchEngine` 同口径，两者金额折算共用本文件引入的 `PieceRateAmountHelper`。

**记录→请求映射（V1.3，共享单源防漂移）**：手工 `match-price` 请求由页面组装的方式已废弃（UI 改点选记录）。成检记录（`FinalInspection`，含所属批次 `ProductionBatch`）→ 请求由 `FinalInspectionMatchRequestMapper.BuildRequest` 单源构建（`MES.Services/Payroll/FinalInspectionMatchRequestMapper.cs`）：ItemKey=InspectionItem、LengthStatus=批次长度状态、Length=`PieceRateAmountHelper.ResolveLengthMm(FixedLength, 状态)`（Range/NonFixed 6000 兜底）、InspectionCount=记录 Quantity、WeightKg=记录 Weight、OD/WT=`SpecificationParser` 解析批次规格、PlantGrade=批次牌号、EquipmentName=记录设备号、**不设 SpecialState**（成检无此取数源，结算采集本就不带，两处一致）。**成检结算采集（PieceRateCollector 成检源）与按记录试算共用本映射**。新增浏览/计价端点（SalaryView）：`GET trial-records`（全局任意跨期记录：成检项目/关键字过滤 + 服务端分页，默认检验日期降序；规格仅展示，避免导航列 InMemory 下推不可靠）与 `GET trial-records/{id}/price`（按 Id 计价，返回 null=未定价；记录不存在抛 `BusinessException`）。

## 7. 数据维护闭环——专用批量导入/导出（2026-09-03，与生产计件同机制）

类别 + 维档父子整组，DataTool 扁平机制无法承载，在类别页提供专用导入/导出。冲突策略 = **覆盖更新**；模板/导出列值全用中文域值（中英容忍），保证「导出→改→再导」闭环；任一数据行无效 → 整体拒绝入库（组级原子性，预览与导入同口径解析）。

- **导出全量**（`ExportAsync`）：当前全量 → xlsx 双 sheet「类别」+「维档」（维度中文、成检项目/长度状态/特殊状态中文回显）。
- **模板**（`GenerateTemplateAsync(kind)`）：kind=category|tier，单 sheet + 1 示例行。示例成检项目 = 「当前无类别」的项目 + 示例行启用=否——原样导入模板不误覆盖真实类别/不误计价。
- **预览 / 导入**：复用 DataTool `ImportPreviewResult`/`ImportResult` 契约，预览统计 新增 AddCount / 覆盖 OverwriteCount / 错误 ErrorCount + 明细，导入事务内覆盖更新。

**模板语义（职责分离、避免误删档）**：
- **类别定义模板**（category）：列 `成检项目/基准价/结算单位/启用/备注`。定位 = 成检项目（OrdinalIgnoreCase，启用优先）。命中 → **更新主属性（基准/单位/启停/备注），绝不清既有档行**；未命中 → 新建（无档行）。文件内同项目两行 → 报错「重复定位」；与既有违例多条启用同项目 → 「同项目启用唯一」报错。
- **维档系数模板**（tier）：列 `成检项目/维度/档值/系数/启用`。定位未命中 → 整行报错「请先导入类别定义」；命中 → **该类别 Tiers 整组替换为文件行**。组内经档重叠/等值去重同口径校验，违例整组拒存不动原档。

**解析口径**：成检项目/长度状态经 `EnumHelper.TryParse` 中英归一、单位 `ResolveUnit`、特殊状态 `PieceRateStateKeys.ToKey`、区间 `PieceRateRangeParser`（检验支数 `ToIntBound` 整带）、维度键 `ResolveDimension`；基准/系数 >0；**解析期错误即置行无效**（`AddParseError`），空行跳过、空表/不可读 Fatal。

**实现**：接口 `IPieceRateFinalInspectionCategoryImportService` + `MES.Services/Payroll/PieceRateFinalInspectionCategoryImportService.cs`；4 端点挂 `api/piece-rate-final-inspection-category`（export-all / import/template?kind / import/preview / import，权限 export+template+preview=SalaryView、import=SalaryEdit）；Controller 构造新增注入第二服务；前端类别列表页工具栏「导出全量 / 导入类别 / 导入维档」+ `PieceRateFinalInspectionCategoryImportDialog` 弹窗（下载模板 → 上传 .xlsx → 解析预览 chips+错误表 → 确认导入）；`MES.Blazor/Services/Payroll/PieceRateFinalInspectionCategoryImportService.cs` 前端服务，DI 双向注册。测试 `PieceRateFinalInspectionCategoryServiceTests`(20) + `PieceRateFinalInspectionCategoryImportServiceTests`(11)。
